# M1：船と富士山の新規ブロックアウト

GPT-6 の実装担当が Blender 5.2.2 LTS で新規制作した、静的な構図検討用の素材です。所蔵館の `Met_JP1847.jpg` から、細長く両端が上がる船と青・白で整理された富士山の構成を目視で確認しました。画像をメッシュへ変換していません。寸法は制作上の仮値であり、船の歴史的実測や富士山の地理的縮尺を再現したものではありません。

## ファイルと実測値

| 素材 | Blender の境界最小 X,Y,Z（m） | 境界最大 X,Y,Z（m） | 三角形数 |
|---|---|---|---:|
| `boat_blockout.blend` / `boat_blockout.fbx` | -0.9, -5, 0 | 0.9, 5, 1.775 | 788 |
| `fuji_blockout.blend` / `fuji_blockout.fbx` | -12, -12, 0 | 12, 12, 8 | 476 |

船の長さは 10 m、最大幅は 1.8 m、船首は Blender の -Y、上は +Z です。船体、左右の縁材、床板 25 枚、横梁 5 本を 5 メッシュにまとめています。船体は外側・内側・上縁・両端を接続した厚みのある開放形状です。側面の内側への基準距離は 0.075 m、底の基準厚さは 0.085 m で、細い両端は断面に合わせて調整しています。

船の中央床面は Z = 0.2825 m。両端に向かって床も上がり、最高床面は Z = 0.4025 m です。後工程で視点の足元や座位の高さを置く際は、この床面と船の配置高さを足してください。船体の Z = 0 は底面であり、喫水や海面高さを意味しません。衝突判定・浮力・操船は本素材に含めていません。

富士山は全周に面を持つ 3D 形状で、底面の半径は 12 m、高さは 8 m。1 メッシュ・2 材質です。青い山体と白い雪の境界は同じ頂点列を共有するため、重なった雪面を載せていません。

## 材質名

- 船体：`GW_Boat_Wood`
- 縁材と横梁：`GW_Boat_Edge`
- 床板：`GW_Boat_Plank`
- 富士山体：`GW_Fuji_Blue`
- 雪：`GW_Fuji_Snow`

Blender の簡単な色を保存しています。Unity の作品用シェーダーへの割当てはインポート工程で行います。

## 座標・書出し

Metric / Unit Scale = 1 / Meters。制作元の全オブジェクトは位置 0、回転 0、スケール 1。原点に対する形状座標へ変換を適用しています。船・山は別の `.blend` と FBX に保存し、それぞれ原点を基準としています。カメラ・照明・外部テクスチャ・アニメーションは制作元と FBX に含みません。

M0 の校正と同じ `global_scale=1`、`apply_unit_scale=True`、`apply_scale_options=FBX_SCALE_UNITS`、`axis_forward=-Z`、`axis_up=Y`、`use_space_transform=True`、`bake_space_transform=False` を使用します。今回は多角形の解釈差を減らすため、FBX は `use_triangles=True` で書き出しています。全フラグは JSON に記録しています。

Unity での軸変換は新規プロジェクトの M0 校正結果を利用し、この FBX 自体も実インポート後に境界・向き・法線・材質を確認してください。本フォルダーの検証だけでは Unity の合格を意味しません。

## 再生成

```text
G:\SteamLibrary\steamapps\common\Blender\blender.exe --background --factory-startup --threads 2 --python-exit-code 1 --python generate_m1_assets.py
```

スクリプトは置かれたフォルダーに同名の生成物を保存します。空シーンから制作し、寸法と法線を測定、blend / FBX 保存、Blender の実描画、blend 再読込、FBX 再読込を行います。

実行は非表示の背景プロセス、2 スレッド、45 秒の実行上限で行いました。終了コードは 0、成功文字列は `M1_BLENDER_ASSETS_PASS`。実行ログは `blender_stdout.log` と `blender_stderr.log` です。Blender 6.0 に向けた `Material.use_nodes` の非推奨警告が出ていますが、今回の実行は成功しています。

## 確認済み・保留

`validation_blender.json` に、版、ファイルの SHA-256、各メッシュの実測境界、三角形数、材質名、法線、保存と再読込の検査結果を記録しています。JSON は実行ごとに生成します。

- 制作元・blend 再読込・FBX 再読込のメッシュは、非多様体辺 0、面積がゼロの面 0、非有限または単位長でない面法線 0、符号付き体積が正。
- FBX 往復の境界誤差は船 0.000000835 m 以下、富士山 0.000001956 m 以下。許容値は 0.00001 m。三角形数と材質スロットも一致。
- `boat_blockout_blender_preview.png` / `fuji_blockout_blender_preview.png` を目視確認。船内の開口、床、横梁、山体の立体感と雪線を確認。船の床板が外側へ突き抜けないよう寸法を修正して再描画済み。
- Unity の表示・寸法・法線、PC ビルド、HMD 表示、操船・浮力は **この担当では未実施**。Blender の画像をそれらの動作証拠には数えません。

この作業では共有リポジトリへ書込み・コミットを行っていません。工程番号ごとの取込み・Unity 検証・記録は主実装担当へ引き継ぎます。
