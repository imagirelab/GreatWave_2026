# 方法说明（§8）— 待您确认

## 选的方法：截面曲线的参数化动画 + 沿波峰线扫掠，全部由 Python（bpy + numpy）生成

1. **截面**：每一帧的大浪由 XZ 平面里的一条截面曲线 C(u, t) 定义，u 从背の裾 → 波頂 → 波頭の先 → 波腹 → 谷，u 就是 UV 的 U。
2. **终幕**：C(u, T) 直接取 `target/base_contour.json`（大形基準輪郭；画面左端以外按 §7b 延伸，被挡住的部分按 §7c 补全）。所以中央截面在终幕**按构造**等于基準輪郭，S1–S7 的误差只剩网格离散误差（U 方向约 420 个采样，弦误差远小于画面高的 0.1％）。
3. **中间帧**：不在顶点位置上做线性混合（会缩瘪、自交、φ 不单调），而是在**切线角–弧长空间**里变形：ψ(s, t) 从“涌”的 ψ 过渡到终幕的 ψ，过渡权重按部位分时启动（背和前面先动＝高まる；波頭上侧随后＝張り出す；波頭の先和下侧最后＝巻き込む）。由 ψ 积分重建曲线后，再用平移和等比缩放让 h(t)、x_c(t) 精确等于设计曲线；t = T 时该变换为恒等，终幕不受影响。第一轮里测试夹具已经用同一思路（切线角变形）在 285 帧上通过了 M1–M6，可作为可行性依据。
4. **运动的依据**：h(t)、θ(t) 的节奏取自 Houdini 参考的实测（高まる : 張り出す ≈ 72 : 28；θ ≤ 30° 保持到 τ≈0.47，30°→80° 在 τ 0.47–0.69；前面竖直时 h≈0.74 H；張り出す期间 h 还在升 0.23 H）。**参考里没有巻き込む，也没有停止前的减速**（缓存在第 55 帧、轮廓速度还是峰值的 87％ 时结束），这两段只能按原画终幕和 M4／M5 来设计：最后 1 秒用 C¹ 的缓出时间重映射，终帧速度为 0，之后形状逐位不变。
5. **三维**：P(u, v, t) = 截面沿 Y 扫掠，两端收束到静水面（裾在 Z=0）。收束方式至少给两个方案（§7a），并用 `CAM_print` 的轮廓测试检查“端部截面不挡住空洞、不抹平波頂”——第一轮已经确认简单的裁剪式收束会挡住空洞，所以这一条由测试把关，不靠目测。
6. **固定拓扑**：网格是固定的 Nu × Nv 网格（提议 420 × 200 = 84,000 顶点，与现有 85,120 同量级），顶点 (i, j) 全程对应 (u_i, v_j)，UV 不变；`crest_rim` = 波頭の先附近的 u 列；逐帧顶点写成点缓存（PC2／MDD + Mesh Cache 修改器），第 4 步导出 Alembic。同一份 `params.json` 重建两次逐位一致（G5）。

## 考虑过但没选的

- **流体模拟（Mantaflow／FLIP）**：轮廓无法控制到 1％／2％（您用 Houdini FLIP 一个月的结果就是这一点）；逐帧拓扑变化，卷浪处用垂直投影重拓扑会失败；单次迭代超过 5 小时。
- **Shape Key／顶点线性混合**：中间形状缩瘪和自交；还需要手工雕刻目标形，违反“不手工雕刻”。
- **Lattice／曲线／Hook 形变器**：对轮廓是间接控制，难以保证 1％。
- **纯 Geometry Nodes**：做得到，但样条数值计算在节点里调试慢，而测试本来就是 numpy；需要的话以后可以把生成器移植成节点。
- **拿 Houdini 网格去变形**：规格禁止。

## 已知风险

- 收束方式挡住空洞或抹平波頂（由轮廓测试把关）。
- 巻き込む期间波腹附近自交（G4 每 15 帧检查；切线角空间 + 分时权重是为此选的）。
- x_c 的行程：参考里波在成长期间行进了约 3.5 H，而原画画面左端只到 −0.86 H；行程做成参数，给默认值和对比图。
