# 方法案（§8）— 当時の確認待ち記録

以下は設計時に作成した方法案です。現行成果物の測定結果は `docs/milestones/` を参照してください。

## 選んだ方法：断面曲線のパラメトリックアニメーションと峰線方向への掃引を Python（bpy + numpy）で生成

1. **断面**：各フレームの大波を、XZ 平面上の断面曲線 C(u, t) で定義します。u は背の裾 → 波頂 → 波頭の先 → 波腹 → 谷の順に進み、UV の U に対応します。
2. **最終姿勢**：C(u, T) は `target/base_contour.json` を直接使います。これは大形基準輪郭で、画面左端の外側は §7b に従って延長し、隠れた部分は §7c に従って補完したものです。したがって中央断面は最終姿勢で、**構造上**基準輪郭と一致します。S1–S7 に残る誤差はメッシュの離散化によるものだけです（U 方向に約 420 点、弦の誤差は画高の 0.1% より十分小さい）。
3. **中間フレーム**：頂点位置を線形混合すると、形が縮んだり自己交差したり、φ が単調に変化しなくなったりするため、**接線角と弧長の空間**で変形します。ψ(s, t) を「うねり」の ψ から最終姿勢の ψ へ移し、部位ごとに異なる時刻から補間します。背と前面が先に動く「高まる」、波頭の上側が続く「張り出す」、波頭の先と下側が最後に動く「巻き込む」という順序です。ψ を積分して曲線を再構成した後、平行移動と等方拡大縮小を使って h(t)、x_c(t) を設計曲線に正確に合わせます。t = T ではこの変換が恒等変換となり、最終姿勢に影響しません。最初の試験では、同じ接線角変形の考え方を使ったテスト用実装が、285 フレームで M1–M6 に合格しました。これを実現可能性の根拠とします。
4. **運動の根拠**：h(t)、θ(t) のリズムは Houdini 参照の測定から取ります（高まる : 張り出す ≈ 72 : 28、θ ≤ 30° を τ≈0.47 まで維持、30°→80° は τ 0.47–0.69、前面が鉛直のとき h≈0.74 H、張り出す間にも h が 0.23 H 上昇）。**参照には巻き込みと停止直前の減速がありません**。キャッシュは第 55 フレームで、輪郭速度が最大値の 87% のときに終わっています。この 2 区間は原画の最終姿勢と M4／M5 に基づいて設計する必要があります。最後の 1 秒に C¹ 連続のイーズアウトとなる時間の再マッピングを使い、最終フレームの速度を 0 にします。それ以後は頂点位置を変えません。
5. **立体形状**：P(u, v, t) は断面を Y 方向に掃引し、両端を静水面へ収束させます（裾は Z=0）。収束方法は少なくとも 2 案（§7a）を示し、`CAM_print` の輪郭テストで「端の断面が空洞を隠さず、波頂を平らにしない」ことを調べます。最初の試験で、単純な切り取り式の収束は空洞を隠すと確認しました。そのため目視だけに頼らず、テストで判定します。
6. **固定トポロジー**：メッシュは固定の Nu × Nv 格子です（提案値は 420 × 200 = 84,000 頂点で、既存の 85,120 頂点と同程度）。頂点 (i, j) は全期間を通じて (u_i, v_j) に対応し、UV は変わりません。`crest_rim` は波頭の先に近い u 列です。各フレームの頂点位置を点キャッシュ（PC2／MDD と Mesh Cache モディファイア）へ書き、第 4 段階で Alembic を書き出します。同じ `params.json` から 2 回再生成した結果は、各値が一致するようにします（G5）。

## 検討したが選ばなかった方法

- **流体シミュレーション（Mantaflow／FLIP）**：輪郭を 1%／2% 以内に制御できませんでした。1 か月間の Houdini FLIP の試行結果もこの問題を示しています。フレームごとにトポロジーが変わり、巻き込み部分を垂直投影で再トポロジー化すると失敗します。1 回の反復に 5 時間以上かかります。
- **シェイプキー／頂点位置の線形混合**：中間形状の縮みや自己交差が起こります。目標形を手作業で彫刻する必要もあり、「手作業で彫刻しない」という条件に反します。
- **ラティス／カーブ／フック変形**：輪郭を間接的に制御するため、1% を保証しにくい方法です。
- **Geometry Nodes のみ**：実現可能ですが、スプラインの数値計算をノード内で調整するのは時間がかかります。テストはもともと numpy で行うため、必要なら後から生成器をノードへ移植できます。
- **Houdini メッシュの変形**：当時の仕様で禁止されていました。

## 既知のリスク

- 端の収束形状が空洞を隠す、または波頂を平らにする可能性があります。輪郭テストで確認します。
- 巻き込みの間に波腹の近くで自己交差が起こる可能性があります。G4 で 15 フレームごとに確認します。接線角の空間と部位別の開始時刻は、この問題を抑えるために選びました。
- x_c の移動距離：参照では波が成長する間に約 3.5 H 進みますが、原画の左端は −0.86 H までしかありません。移動距離をパラメータにし、既定値と比較画像を示します。
