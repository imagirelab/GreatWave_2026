## 原画に対する測定と不確定点

原画は Tsunami_by_hokusai_19th_century.jpg（3859×2594 px）のみを形状の正解とした。領域法Aと輪郭追跡法Bの差を比較し、差が画面高0.5％を超える可視部4箇所を原画の局所拡大で裁定してBを採用した。指状尺度の決定手順は src/contour/build_base_contour.py と base_contour_params.json に記録している。

| 波頂 | 左38.22％、上8.62％。上部は約5％の幅を持つ平坦部 |
| 内側の弧の最深点 | 左39.56％、上46.92％ |

| 指状尺度自身のS8 | 背23°、波頭86°、内側の弧67°。いずれも15°制限を超える箇所がある |

谷は手前の波に遮られており、原画から実際の水位を測定できない。座標系の Z＝0 は当時の指定値、画面上から74.7％に置いた。背の左端も解釈が二つあり、white_body_outline を採用したが未確認。x約338 pxより左には直接描かれた墨線がなく、白い浪体の可視縁を実測線幅8.84 pxだけ外側へ移す構築線である。sky_silhouette を採ると左端で縦方向に約6.8～7.2％変わる。

波頭先端の向きも定義によって変わり、指状尺度では張り出し領域の主軸−45.8°、波頂→先端−36.8°、テストのφは+5.4°だった。S5にどれを用いるかは当時の検討課題だった。後の測定ライブラリ改訂ではモデルと目標を同じφで測るようにしたが、その定義自体の妥当性は目視検証を要する。

## 大形輪郭の作り方と結果

S8の1％間隔＝25.94 px、15°は0.2618 radなので、必要な曲率半径の目安は99.1 px。指状尺度を閉じた領域にし、円盤による**閉処理→開処理**を施し、境界をサブピクセル化して1 px間隔に再標本化した。元線との差が0.15％未満で、元線の転角も半径から決まる限界以下の場所では元線を残した。移行部は2％長の smoothstep で接続した。開処理→閉処理では波頭の細い首が切れ、半径150 pxで先端 x が約1920 pxまで退いてしまったため採らなかった。

| 半径 | 自身のS8最大値 | 当時の判断 |
|---:|---:|---|
| 100 px | 15.2° | 制限を超える |
| 120 px | 12.7° | 制限内だが余裕が小さい |
| 135 px | 11.5° | 当時の11°余裕目標を超える |
| 150 px | 10.3° | 当時の正式版 |

半径150 pxの先端は (2193.0, 831.0) px＝左56.83％、上32.04％。指状尺度との差は先端で2.19％。背の平均／95％／最大偏差は0.01／0.05／0.14％、波頭0.54／2.16／2.67％、内側の弧0.70／3.41／3.88％。最下部の泡沫塊が最大で3.88％削られる。波頭縁の内接円直径は大形輪郭自身で約17.6％ Hであり、G3の3％ Hとは両立しない。この問題は網目化だけでは解消しない。

大形輪郭はS8を満たすが、手描きの背に起伏があるため S4.flattens_towards_crest は16.6°の再増加で不合格のまま。掃引網目で空洞を塞いだ旧クリップ方式では S7 と S8 も失敗したが、後の lift_clip でその部分は解消した。正式輪郭のJSON接合点と検出点の差は波頂0.123％、先端0.001％、最深点0％で、0.2％以内だった。
