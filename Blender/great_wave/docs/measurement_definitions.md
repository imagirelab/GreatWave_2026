# 輪郭と断面の測定定義

> この文書は当時の中国語記録を日本語で整理したものです。元の全文は変更前のコミット 0b0178eb9ea6b99ff685d608d557e49068066bb8 で確認できます。数値と判定は当時の記録であり、現在の成果を再検証した結果ではありません。

対象実装は src/gw/raster.py、src/gw/silhouette.py、src/gw/profile_metrics.py。自己検証は tests/selftest_measure.py、合成波は tests/fixtures/make_synthetic_wave.py。判定閾値はここではなく tests/thresholds.json に置く。

## 共通の座標と投影

位置は波高 H に対する (X_H, Z_H) で表す。波頂は (0, 1)、谷の静水面は Z＝0、+Xは船側。距離誤差は画面高の百分率で表し、1％＝25.94 px＝0.0151515 Hである。CAM_print は+Y方向を見る正交カメラで、評価後の世界座標三角形をXZ平面へ投影する。

raster.py は画素中心が閉三角形に入る場合を被覆とし、走査線と累積和でマスクを作る。水面より下を充填するため、静水面以下の谷はマスク上では見えない。silhouette.py は左端、波頂、先端、波腹、内側の弧、谷、右端の順に順序付き輪郭を抽出する。脱離成分、穴、非有限頂点、切り捨てた三角形は別途数えて報告する。Cyclesとの比較や暴力的な参照ラスタライズを使った検証結果は、変更前コミットの第1・2章に残る。

## 単一フレームの指標

- h は波頂と静水面の高さ、x_c は波頂の水平位置。θ は船側の前面の最急傾斜、o は先端が波頂の鉛直線から船側へ張り出す距離、φ は先端より弧長2～8％ H手前の上面の弦方向とした。
- S1・S2・S3・S5・S6 の数値は position_checks が返す。S3 は静水面からの高さと、モデル自身の谷を基準にした高さを区別する。海面を画面高の3％上げた検証例で前者の偏差は+0.034、後者は−2.966だった。テスト層での判定の扱いは tests_readme.md を参照する。
- S4 は背の傾きと上部の曲率、S8 は一定弧長間隔での接線角の差を測る。先端周辺の除外範囲や窓角は当時の解釈である。頂点窓角は報告専用で、正式目標自身が19.1°を示すため15°をそのまま適用できない。
- S7 は背・波頭・内側の弧を分け、モデル→基準と基準→モデルの双方向最近接距離を測り、悪い側を採る。遮蔽による補完区間 in_S7=false は除外し、除外率も報告する。符号付き距離は浪体の外側を正とするが、平均だけでは相殺が起こるため分位点も読む。

波頭先端は波頂から最初に静水面へ達する区間で、水平戻り量が最大の先端を選ぶ。旧規則は最初の小さな瓣で止まり、指状目標ではJSON接合点から15.9％ずれた。新規則では0.008％になり、単一の先端の合成波61時刻とHoudini参照110輪郭では旧規則と同じ結果だった。目標JSONの接合点と同じ輪郭から検出した点を比較し、差0.2％以内かを調べる。差が大きいと S5／S7 は同じ部位を比較していないため、試験は INVALID とする。

## 報告専用の形状量と既知の盲点

W は絶対高さ Z＝0.25／0.5／0.75 Hで切る断面幅、波頂からの距離、張り出し、空洞深度、面積を報告する。正式基準輪郭は Z＝0.509 H で背が画面左端に達するため、z25 と z50 の「幅」は画面端からの値となる。5％／8％の水平方向拡大は合成例の z75 で+5.00％／+8.00％と読めたが、これらの指標には閾値を設定していない。

shape は各輪郭の**自身の波高**の0.25／0.5／0.75を切り、幅をその波高で割る。幅+5％、高さ−1.9％の組合せでは相対形状は約+8.1％となるが、絶対高さで切るW.z75は−5.22％と逆方向に読めた。0.5 hの縦横比は背が画面端で切られるため比較不能とし、0.75 hの値を見る。これも報告専用である。

孤立した網目が投影で主体と重なる場合、脱離成分の検出だけでは見つからない。谷水位は最深点以後の最も低い点を採るため、前面近くの局所的な海面上昇が遠方の Z＝0 に隠れる可能性がある。最大戻り規則は二つの空洞の大小が入れ替わると先端を飛び移る可能性がある。当時の合成波と参照輪郭ではその事例は確認されなかった。

## パラメータと再実行

DEFAULT_PARAMS と params.json の measure_params、S8_sample_spacing_pct が測定定義を決める。未知のパラメータ、壊れたJSON、型違いを黙って既定値へ戻さず例外にする。既定値から変えた項目は non_default_params に記録する。当時の工程では空の辞書だった。

再検証は tools/run_blender.ps1 に tests/selftest_measure.py を渡す。当時の最終記録は88項目・失敗0である。数値的な誤差と所要時間の元表、全ての暫定解釈は変更前コミットの第4～7章、および tests/thresholds.json と実装で確認できる。
