从表里直接看到的几件事（仍是事实，都是表观量）：

1. **先变尖变陡，后长高**：(a)→(b) 只完成了 27% 的表观上升，但右侧靠顶处的表观坡角已从约 30° 变到约 73°，轮廓从左右对称变成「左长右短、左凸右凹」。
2. **上升速度是「慢—快—慢」**：相邻帧的表观上升为 16 → 30 → 14 → −1 px；最高点前后有约一帧间隔（(d)–(e)）几乎不升不降。
3. **波頂边升边向右移**，移动也在减速：相邻帧 +24 → +39 → +21 → +5 → +5 px。右边的小尖峰则基本停在原地（x ≈ 293–295），最后消失。
4. 顶部朝右勾、白水落向右侧，和波頂移动的方向是同一侧。
5. 隆起在画面里的**宽度几乎没变，高度变成约 3 倍**：(a) 半高处宽约 72 px、表观高约 32 px；(d) 半高处宽约 85 px、表观高约 92 px（基准面读得粗，±10 px）。
6. 白水只出现在棱线和勾过去的那一侧；迎面的长坡（左侧）从头到尾是光滑的。

### 【推测】

- 波頂向右移 = 两组波的平均传播方向在画面里指向右；论文说垂直于平均方向的水平速度互相抵消，沿平均方向的分量不抵消，所以水柱不是纯竖直上抛，而是「向上 + 略向前（画面右）」。这解释了 (d) 的右勾和 (e) 的右落。相机朝向未读到，所以这只是推测。
- 右边的小尖峰大概是交叉波形成的菱形峰格里相邻的一个交点（或其中一组波自己的波峰）。论文页面里没读到对它的说明。
- (c) 里「顶在右、下面的绿水边界在左」看上去像悬垂，实际是金字塔的棱线被斜着看到，**不能**当成张出量 o 来量。

## 4. 对「平静海面 → 原画峰值姿态」的动画：能借什么，不能借什么

### 4.1 时间尺度的换算【事实：计算】

- 把 Draupner 波按 Froude 相似缩到 `WAVE_HEIGHT_M` = 11 m（谷から波頂 对 波高 25.6 m）：时间比 √(25.6/11) = 1.526 → 一个帧间隔 = 0.388 s；(a)→(d) = **1.16 s ≈ 35 帧（30 fps）**；相当的周期 Tz = 8.2 s，半个周期（谷 → 波頂）= 4.1 s，四分之一周期 = 2.05 s。
- 如果改用 波頂高 18.5 m 对 11 m 来缩：一个帧间隔 = 0.456 s，(a)→(d) = 1.37 s。
- 说明书 §6.5 的初期设定：高まる 4 s / 張り出す 3 s / 巻き込む 2.5 s，共 9.5 s。

【推测】

- 「高まる 4 s」和 Froude 相似波的半周期（4.1 s）是同一量级，物理上说得通。
- 「从已经成形的隆起到最高点」在相似尺度下只要 1.2–1.4 s，而说明书给 張り出す + 巻き込む 共 5.5 s → 后两段相对物理实时大约是 **4–5 倍的慢动作**。这不是缺陷，是演出上的选择；是否保留由用户决定（说明书 §6.5 已规定总长 9.5 s、比例参考 Houdini）。
- 按深水近似 c = gT/2π 估算，T = 8.2 s 的波相速约 13 m/s，9.5 s 里会走 100 m 以上（约 11 H），远超原画画面宽 2.25 H。所以 x_c(t) 的幅度不可能照物理相速来，必须以 Houdini 参考里实际的位移为准，或者把观察系看成大致随波移动。（kd = 1.6 不算深水，这个估算只看量级。）

### 4.4 同一篇论文的 Figure 3（Δθ = 0°）更接近「巻き込む」

【事实】（我在浏览器里看了 Figure 3 原图，六格，同样 100 ms 间隔）：波从画面左向右行进；(a)–(c) 波頂宽而圆，前面（右侧）很陡；(d) 前面上缘出现一条小水舌；(e) 水舌向前翻成一个小筒；(f) 水舌砸在前面的上部，出现白水。翻卷的部分只占前面上部的一小段，浪高的大部分不参与卷入。论文对它的说法是：前面先形成近乎竖直的水墙，再从那里伸出 plunging 的水舌。

【推测】对 張り出す → 巻き込む 的顺序，Figure 3 比 Figure 4 更有参考价值：前面先立到近乎竖直（θ ≥ 80°，对应 M2 的终点）→ 水舌从前面的**上缘**伸出（o 开始增加，对应 M3）→ 水舌的朝向从水平逐渐转向下（φ 单调向下，对应 M4）。但实验里的卷入规模比原画小得多（原画的空洞几乎贯穿整个浪高），所以原画的终幕是夸张化的 plunging 姿态，幅度只能由基準輪郭决定。

【常识性背景，本次未查原文、不引用数值】经典的 plunging 破碎研究（Longuet-Higgins & Cokelet、New–McIver–Peregrine 等）描述的顺序相同：前面变陡到竖直 → 波頂前缘射出水舌 → 水舌近似抛体下落、朝向不断下转；射出之后波頂高度略降。说明书 M3 允许的「h 下降 ≤ 5％」与此相容。

## 5. CG 参考图（`images/2.webp`，Houdini 视口截图）的三维结构理解

按说明书 §3：这张图**只用来理解三维结构，不是形状的正解**。我只做了目视描述，**没有从它量任何比例、坐标或轮廓**，下面也不给数值。

### 【事实】（图上看到的）

- 视角：透视视口，机位略高于海面，大致沿波峰线方向看过去，构图近似原画（背在左，波頭朝右卷）。画面里有包围盒线框和地面网格；左下有一个绿色小点（是什么未读到）。
- 海面：四周是起伏的粗糙海面，不是平面。浪体从一片很宽的低矮隆起上升起来，浪脚和周围海面是连续过渡的，没有明显的接缝。
- 浪体怎样从海面升起：左侧（背）是一条长的斜坡，半高附近有一道较低的肩部 / 次级的脊，再往左融进粗糙海面；浪体下宽上窄。表面的拉伸纹从浪脚一直拉到波頂，到顶部附近朝右弯 → 表面材料是「先被向上提，再朝右翻过去」。
- 波頭朝哪边卷：朝画面右（船の側）。右上角有一条很薄的、向右并略向下勾的唇缘；唇缘下面，浪体右侧的外形是一条光滑的凹弧（对应 内側の弧），向下收进谷，再沿水面向右展开。
- 朝相机的这一面上有数条从浪脚到波頂的粗大纵向褶皱（肋状），呈扇形向波頂收拢。
- 沿波峰线方向两侧怎样收束：浪体在中央最高；朝相机的这一端是逐渐降低、向前向左铺开的斜坡状「裙边」，最后融进海面，**不是**把截面直接切断的端面；远端被浪体自己挡住，看不到。右后方远处另有一个独立的低矮隆起，不属于大浪本体。
- 白水（米色粒子）的位置：(1) 波頂 / 波頭上方有一大团，沿波峰线分布，整体向上、向右后方扬起，盖在波頭的顶面和外缘上，空洞里面没有；(2) 浪脚、靠相机一侧的海面上有两片贴着水面的薄层，一片在左（左边缘是一条笔直的切边），一片沿右侧凹面的脚下向右延伸。背的斜坡上和凹面本身上没有白水。

### 【推测】

- 纵向的肋状褶皱多半是 FLIP 粒子成面 / 网格拉伸留下的痕迹，不是用户想要的造型特征；说明书 §2 也把 縞 排除在这次范围之外。新网格的侧面应当是光滑的。
- 左边那片白水的笔直切边，多半是白水发射区域（包围盒）的边界，不是物理特征。
- 用户想要的「三维感」主要来自三点：浪体从宽阔的隆起上连续升起（裾 平滑接到海面）；沿波峰线方向两端逐渐降低收束而不是一刀切；波頭只在中央一段高高卷起。

### 【建议】（给 §7a 的方案设计）

- §7a 至少要两个方案。可以考虑：**方案 A**＝中央一段保持同一截面，两端用一段平滑的过渡把高度和张出一起收到静水面；**方案 B**＝「短峰」型，截面高度沿 Y 按钟形包络连续变化（水槽的 Figure 4 说明这种短峰在物理上是存在的，侧影同样像原画）。
- 无论哪个方案，都要满足说明书 §5 注意事项里的约束：从 `CAM_print`（正交、沿 +Y）看，空洞不能被近处或远处较低的截面挡住。较低的端部截面如果只是整体缩小或只沿 Z 压低，它的波頭 / 前面会落进中央截面的空洞里，S2 和 S7 就会失败。比较稳妥的条件是：**任何端部截面在 `CAM_print` 下的投影都落在中央截面的轮廓之内**（端部截面的前面不得越过中央截面的内側の弧向右）。实现上可以让端部先收张出（o → 0）、再降高度，或者让缩放的锚点放在背的一侧。这一条需要在第 2 步用测试（S2 / S7）实际验证，我没有验证。

## 6. 建议汇总（给方法设计 / 动画设计，以及用户）

1. 运动节奏的主依据仍是 Houdini 参考（§6.1）。本笔记的表观曲线只用来交叉检查：如果 Houdini 参考里也是「θ 领先于 h」「h 为慢—快—慢」「x_c 减速靠近终点」，就可以放心采用；如果不一致，以 Houdini 为准并把差异报告给用户。
2. h(t)：S 形；终幕放在 h 的最高点。θ(t)：在 高まる 的前半段完成大部分变陡。x_c(t)：单调、减速地到达 X = 0。浪体底宽在 高まる 中大致不变。
3. 張り出す / 巻き込む 的几何过程不要参考 Figure 4；要看实验照片的话，看同一篇论文的 Figure 3（Δθ = 0°）。幅度完全由基準輪郭决定。
4. 需要用户决定 / 知情的事：说明书的 9.5 s 相对 Froude 相似的物理时间，后两段约是 4–5 倍慢动作（4.1）。我不建议改，只是告知。
5. §7a 的方案设计注意第 5 节的「投影包含」条件。
