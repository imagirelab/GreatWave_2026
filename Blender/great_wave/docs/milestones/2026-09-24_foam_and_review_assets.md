# 2026-09-24：独立した白波、2 視点での確認と閲覧用ファイル

## 対象と方法

この段階では、『神奈川沖浪裏』の**最大の波**の動きと最終姿勢の大まかな形だけを検証します。本体は 84,621 頂点の固定トポロジーメッシュで、285 フレーム / 30 fps の後に 60 フレーム停止します。位置は曲線パラメータで制御し、PC2 点キャッシュに書き出します。これは造形を優先したアニメーションであり、Houdini による流体シミュレーションではありません。

側面は従来の硬い切り取りから、徐々に狭まる形へ変更しました。その後、中央の直線部分の半幅を `0.35H` から `0.10H` に縮め、両側をそれぞれ `2.10H` に延ばしました。全幅は `4.4H` のままです。実験では、波頭の最大前進量の 95% に達する平らな峰線部分の幅が `1.176H` から `0.740H` になり、約 37% 縮小しました。正面からの輪郭は変わりません。独立した白波は波頭の縁のメッシュ 1 つと、2 層の波の爪のメッシュで構成し、それぞれに点キャッシュがあります。最も右に伸びる爪の中心は、原画座標 `(2288, 857)` に合わせました。爪の付け根も細くし、以前目立っていた短い青い帯を取り除きました。白波の形と動きは手動で制御しており、水理学的な正確さは示していません。

## 正式な形状・運動テスト

この PC の Blender 5.2.2 LTS で実行した最新の `tests/run_all.py` の完全な結果は、Git 除外対象の `results/20260924_053338_all/` にあります。このテストの対象は**波本体のメッシュ**です。独立した白波については、`tests/check_foam_animation.py` を使い、2 種類のアニメーションシーンを保存・再読込して第 1、210、285 フレームを確認しました。3 つの独立した PC2 はヘッダーと長さが正しく、頂点値は有限で、後半にも動きがあります。最も遠い爪の中心と目標座標の差は 0.001 ピクセル未満です。テスト設定の監査結果は `non_default=[]`、`unlisted=[]` でした。

| --- | ---: | --- |
| S7 波背 / 波頭 / 内側の弧の p95 輪郭誤差 | 画高の 0.01239 / 0.00750 / 0.00792% | すべて合格。閾値は 2% |
| S8 接線角の最大差 | 10.901° | 合格。閾値は <15° |
| M1–M6 の運動 | すべて合格。M6 の不連続比は 1.194 | 合格。M6 の閾値は <3 |
| G4 自己交差の抽出検査 | 0 | 合格 |
| G5 決定的な再生成での最大差 | 0 m | 合格 |
| S4 波頂に向かう傾斜の緩み | false | 不合格。目標輪郭をそれ自身と比較しても false |
| G3 波頭先端の厚み | 11.635% H | 不合格。閾値は ≤3% H |

**総合テストの終了コードは引き続き 1 です。** S4 は目標輪郭自体が不合格になるため、その輪郭への厳密な一致と文章で定めた判定条件が衝突しています。G3 の厚い波頭先端は、現在の原画由来の大まかな形状目標に沿っています。3% H を満たすには、先端形状を変えるか、薄い水のシートの検査範囲を定義し直す必要があります。閾値を無断で緩めることはできません。白波はこの本体メッシュ用のテストを受けていないため、本体の合格結果を白波へ当てはめることはできません。

## 再生成の順序

`Blender/great_wave/` で以下のスクリプトを実行します。`tools/run_blender.ps1` は `params.json` からこの PC の Blender のパスを読み取ります。別の PC では、先にこのパスと、ほかのローカル専用パスを修正してください。

1. `src/gwave/build_great_wave.py`：波本体の `.blend` と約 289 MB の本体 PC2 を生成します。
2. `src/gwave/apply_ukiyoe_style.py` **または** `src/gwave/apply_procedural_ukiyoe.py`：それぞれ原画投射、またはプロシージャルマテリアルのシーンを生成します。
3. 選んだシーンに `src/gwave/add_animated_foam.py` を実行し、独立した白波の PC2 と白波付きシーンを生成します。
4. 白波付きシーンに `src/gwave/export_final_pose.py` または `src/gwave/render_motion_video.py` を実行し、静止確認用ファイルと動画を作成します。
5. `tests/run_all.py --build-script src/gwave/build_great_wave.py --final-frame 285` で本体を再検証し、白波付きの `.blend` には `tests/check_foam_animation.py` を実行します。本体の再生成テスト中に、同じ本体 PC2 に依存する白波のベイクを同時実行しないでください。

## 未解決の点

プロシージャルマテリアルでは波背の模様が疎らで、紙の白と濃い青の境界が柔らかすぎます。斜めから見た波頭先端は、まだ直線的な梁に見えます。波の爪の数と形も、原画の密集した白波には届いていません。Houdini による物理的な波、Unity でのリアルタイム性能、舟のモデルと操船、HMD の快適性、複数視点からの原画への美的な一致は未検証です。原画画像の出典と使用上の制限は `reference/README.md` を参照してください。
