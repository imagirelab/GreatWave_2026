# 大波の動きの判定表：展示映像の観察と低解像度流体の比較

## 結論

**この参考映像から、同じ大波の形成・着水・破砕・消散の全過程を実測したとはいえない。** 爪状の前縁、深い開口、前方へ広がる波冠、前景へ迫る動きは確認できる。一方、54～60秒では主波の下部が画面外や前景の波に隠れ、約57.2～57.7秒には白い近景が主波を覆う。これを着水衝突や消散の証拠として使わない。

以下の表は、**観察済みの画面**、**参考では未確認の事象**、**自分たちの流体計算が提出すべき証拠**を分ける。見た目の一致と流体としての検証は別々に判定する。今回の観察はHMD、Unityの実時間性能、展示全体の物理的正しさを検証していない。

### 時間の合わせ方

1. 展示から直接比較できるのは、上表の**見かけの区間の比**である。まずAの前縁が読み取れる約0.80秒と、その後の遮蔽約0.50秒を併記する。遮蔽の時間を「接触後の破砕時間」に置き換えない。
2. 自分たちの計算では「高峰が読める時刻」「下降開始」「初接触」「接触後の変形」「低波への移行」を実際の保存時刻から記録する。比較動画の再生速度を変える場合、計算時間と再生時間の両方を示す。
3. 形成・接触・消散の正解秒数はこの資料から決められない。11mという現在の表示寸法に、展示の約1秒の見かけの動きをそのまま割り当てない。水深、重力、入射条件、誘導を外した区間を決めた後で時間尺度を確認する。
4. 全行の判定は「確認済み」「不一致」「この解像度では保留」で残す。見えない段階を自動的に合格扱いしない。

## 4. 静的な参考模型から使う形の目標

[既存の実断面比較](2026-09-24_reference_actor.md)では、参照模型の前後長/Hは1.619、峰方向の幅/Hは1.375、高峰から唇の前伸しは0.557～0.652H、前伸し80%の位置の上下鉛直間隔は0.272～0.466Hだった。前段階の掃引模型は前後長/Hが6.648で、前伸しは0.428Hだった。

これらを最初の単色の形状表示比較で併記する。特に「長い平らな裾」「短く薄い唇」「峰方向へ等高に続く梁」への後退を検出する。中央と両側の実断面、上面、斜め方向を同じ時刻で比較し、左右の収束と開口を確認する。数値帯を満たしただけで美術的な完成と判定しない。

元模型の水線を元Y=2.5と置いたこと、H=11mへの変換は作業上の仮定である。上下鉛直間隔は表面法線方向の厚さではない。模型は静止した一姿勢であり、そこから速度場・水圧・砕波の自然な時間発展は得られない。

最初の低解像度流体の合格に必要なのは、少なくとも**固定側面で形成・前伸し・巻下げ・初接触を追えること**と、その直後の水体の変形が提示されることである。細かい飛沫、消散の時間、浮世絵の最終的な白波表現は、未解決ならそのまま保留と記録する。展示の迫力が似ているという感想で、この判定を代用しない。
