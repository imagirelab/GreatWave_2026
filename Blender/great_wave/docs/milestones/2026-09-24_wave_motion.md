# 2026-09-24：动态大浪的可重建里程碑

## 本次实现

- 将已有 Blender 研究工程迁入 GitHub 工程的 `Blender/great_wave/`。参数、目标轮廓、脚本、测试与参考图均有版本管理；PC2 缓存、生成的 `.blend` 和测试结果可在本机重建，故不提交大文件。
- 保留 421 × 201 顶点的固定拓扑、285 帧 / 30 fps 的浪体动画。波从接近平坦的涌浪抬升，在第 153 帧左右出现张出、第 210 帧左右转入卷入，最终保持 60 帧。
- 将侧翼改为 `lift_clip`，防止三维侧面在正侧投影中遮住浪头下方的空腔。将浪头转向、伸长与整体高度分开控制；浪高由五个显式关键点作单调插值。终帧的中心截面仍精确返回原画目标截面。
- 中心平直段半宽从 2.2 H 减至 0.35 H，侧翼各为 1.85 H；整体沿浪峰方向的宽度为 4.4 H。这使斜视的“长墙”缩短，但端面仍显生硬，需继续改良。

本方法是艺术指导的网格动画，并非 Houdini 流体计算；物理准确性仍须独立验证。

S4 失败是当前目标轮廓和文字条件互相冲突，不能靠偏离目标造型来掩盖。G3 的厚度来自原画中圆钝的浪鼻，且中心截面自身约为 11.6% H；直接削至 3% H 预计会显著改变画中轮廓。后续应区分薄水片和另做的白波团块，分别检查其几何，再决定 G3 是否仍适用于整块可见外形。

测试报告还标记 `NON-DEFAULT SETTINGS`，原因是测试代码与阈值文件的默认设置元数据不一致；该标记不等于上述数值检查通过。正在单独审查此测试框架问题。

## 下一步及尚未证明的要求

1. 使沿浪峰方向的端面自然收束，保持正侧轮廓通过，重新测 G4/M6 并检查船视角。
2. 把白波团块、浪爪做成独立可动画几何，终幕最右端需比主体浪头再伸约 95 原画像素；单独验证覆盖、形状与动态。
3. 设计各方向均可用的浮世绘蓝、浅青、暖白材质，避免直接投射的斜视拉伸。与原画按区域对比色彩和白波分布。
4. 生成可供实时环境使用的资产并测性能；本次未验证 Unity、HMD 或流体物理准确性。

这些项目尚未完成，本里程碑不代表整个作品验收通过。
