## 当時の工程構成と再現性

同じパラメータから同じ形状とアニメーションを再生成し、状態を .blend ファイルだけに閉じ込めない方針だった。params.json に尺度・画面・時間・入出力を置き、src/gw/ に基盤処理、src/contour/ に基準輪郭、src/ref/ にHoudini運動の読取、tests/ に閾値と自動試験、target/ に目標輪郭、results/ に画像・数値・ログ、docs/records/ に作業記録を置いた。

当時は Blender 5.2.2 LTS と同梱の Python 3.13／NumPy 2.3.4 を使用し、追加パッケージなしで無画面実行した。G:/research/Wave Simulation/blender/great_wave/tools/run_blender.ps1 が完全ログと終了コードを記録し、画面には GW 接頭辞の行を表示した。旧パスは移転前の参照であり、現在の場所でそのまま実行できるとは限らない。

## 座標と評価条件

| 項目 | 当時の定義 |
|---|---|
| 原画 | 3859×2594 px、左上原点、右向きに x、下向きに y |
| 規格化座標 | 波頂 (0, 1 H)、谷の水面 Z＝0、+X は船側 |
| 画面高の1％ | 25.94 px＝0.0151515 H。水平方向の距離も画面高に対する百分率で表す |
| 初期波高 | H＝11 m、許容範囲10.4～13 m |
| CAM_print | +Y方向を見る正交カメラ、3859×2594 px。原画と比較する視点 |
| 時間 | 30 fps、285フレーム。初期区間配分4／3／2.5秒 |

波頂の画面位置は左から38.2％、上から8.7％、波高は画面高の66.0％。ここから画枠は左右−0.861042 H／+1.392994 H、上下+1.131818 H／−0.383333 Hと導いた。

tests/thresholds.json は原仕様の spec と、2026-09-20 の対話で示された「誤差率5％以内」を暫定解釈した user_relaxed_5pct の二段階を持つ。後者の解釈は当時未確認だった。試験では両方を報告し、合格のために基準輪郭・閾値・比較カメラを変えない方針だった。
