## 再実行と出力

Blender の無画面実行では tools/run_blender.ps1 に tests/run_all.py を渡し、保存済み .blend と --object、または --build-script と --build-arg を指定する。単独検証は test_shape.py、test_motion.py、test_mesh.py を同様に呼ぶ。直接 Blender を起動する場合は --background --factory-startup --python-exit-code 1 --python を用いる。旧記録の G:/research/Wave Simulation パスは移転前のもので、現行の配置に合わせて指定し直す必要がある。

--build-script は空の初期状態のシーンに関数 build_for_tests、build、build_object のいずれかを読み込み、波の対象を生成する。G5 はこの再生成手順が必要。--object は複数の波体をカンマ区切りで指定でき、未指定の物体は形状判定に含まれない。

各回は結果フォルダに metrics.json、summary.md を作る。形状は原画重ね合わせ、局所拡大図、S4・S7・S8 の図、運動は曲線・速度・15フレームごとの接触図、網目は裾・縁厚・自己交差図を保存する。数値に加え画像を目視確認する。

| 結論 | 当時の意味 | 通常の終了コード |
|---|---|---:|
| PASS | 有効で、必要な判定項目が全て測定され、違反なし | 0 |
| INCOMPLETE | 違反はないが必要項目が未実施 | 1 |
| FAIL | 有効な測定で違反または測定不能の項目がある | 1 |
| INVALID | 幾何や輪郭の有効性条件を満たさず、数値を信用できない | 1 |
| ERROR | スクリプトまたは引数に誤りがある | 2 |

判定に影響する設定を --set 等で変更すると NON-DEFAULT SETTINGS を付け、単なる PASS と扱わない。--skip や --only による欠項目は INCOMPLETE。実行開始時に旧結果を stale_ 名に移し、RUNNING 印が残った実行を完了結果として扱わない。原仕様 spec と暫定 user_relaxed_5pct の両方を報告し、既定の終了コードは spec を使う。

## 形状検証

CAM_print で評価網目を投影し、順序付き輪郭を抽出して基準輪郭と比較する。

| 項目 | 判定の要点 |
|---|---|
| S1 | 波頂位置の横・縦偏差 |
| S2 | 内側の弧の最深点位置 |
| S3 | 谷から波頂までの高さ。静水面を基準とする値とモデル自身の谷を基準とする値を併記・判定した |
| S4 | 背の中段が最も急で、波頂へ緩やかになり、上部に折れがないこと。角度自体も報告 |
| S5 | 爪を除く波頭先端の位置と末端上面の向き φ |
| S6 | 爪を含む原画外縁より波本体が左にあること |
| S7 | 背・波頭・内側の弧の双方向最近接距離。各段で平均と95パーセンタイルを判定 |
| S8 | 画面高1％間隔での最大接線角差。先端付近2％は除外し別報告 |

NaN／無限大の頂点、脱離した輪郭成分、静水面に届かない終幕、基準輪郭で S7 対象外の割合が35％を超える段、輪郭接合点のJSONと検出値の差が0.2％を超える場合などは INVALID とした。35％と0.2％の設定は当時の解釈であり確認待ちだった。対象外の物体数は報告するが自動判定できない。

W 系の幅・面積・張り出し、自己波高で規格化した shape 系の縦横比、符号付き S7 偏差、波頭下面・波腹の差、S8 の頂点窓角は**報告専用**で、PASS／FAIL に含めない。幅5％と高さ−1.9％の組合せは従来の判定から漏れる場合があり、shape 系では約+8.1％と読めた。報告専用量に閾値を採用するかは未決定だった。

## 運動検証

各フレームの高さ h、波頂位置 x_c、前面傾斜 θ、張り出し o、先端向き φ、輪郭移動量を測る。M1 は初期傾斜30°未満、M2 は立ち上がり時の高さ単調増加と θ の30°以下から80°以上への変化、M3 は張り出し o の単調増加と高さ低下5％以内、M4 は巻き込み時の φ の下向き単調変化、M5 は停止時速度が全期間最大の20％以下で停止後変位0、M6 は突跳比3未満を判定する。

区間境界と M6 の分母の定義は当時の解釈だった。M2–M4 の測定雑音下限は高さ1e-4 H、角度0.2°とし、原値も保存した。M5の「停止前1秒で徐々に減速」には当時の閾値がなく報告のみ。バックログにある M6 の中央値式と10秒保持・0.2％条件も別途報告のみ。Houdini比較は図示し、参照には巻き込みと停止がない旨を明記した。

## 網目検証と自己検証

G1 は頂点・面・UV構造が全期間固定、G2 は裾の静水面との段差が波高の1％未満、G3 は可視の波頭縁の内接円直径が3％ H以下、G4 は終幕と15フレームごとに真の自己交差なし、G5 は同一パラメータから別プロセスも含めた再生成で頂点差0 m。G3の幾何定義とG4の接触・退化面の扱いは当時の解釈である。G5を実施できない場合は合格ではなく INCOMPLETE。

tests/selfcheck_tests.py で合成波への正常例・故障注入を確認した。当時の強化後は38組の自己検証が0件不一致だったという記録がある。これはテスト枠組みの確認であり、実作品が全項目を通ったことを意味しない。重要な既知の盲点と未達成項目は docs/records/step1_harden_tests.md と現在のマイルストーン記録を参照する。
