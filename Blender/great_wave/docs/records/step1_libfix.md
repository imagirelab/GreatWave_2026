# 第1段階記録：先端測定と報告専用指標の修正（2026-09-20）

> この文書は当時の中国語記録を日本語で整理したものです。元の全文は変更前のコミット 0b0178eb9ea6b99ff685d608d557e49068066bb8 で確認できます。数値と判断は当時の記録であり、現在の成果を再検証した結果ではありません。

変更箇所は src/gw/profile_metrics.py と関連テスト。閾値、基準輪郭の点、カメラ、合成波の解析形状は変えていない。測定定義は docs/measurement_definitions.md、試験の使い方は docs/tests_readme.md にある。

旧先端規則は、波頂の後で最初に水平の戻りが0.3％を超えた局所点を選んだ。指状尺度のような複数の泡の小片の波頭では最初の瓣で止まり、JSON接合点から**15.9％**ずれたため、目標自身でも S5 と S7 が不合格になった。新規則 max_reversal は空中へ張り出す波頭の全区間で水平戻りが最大の先端を選ぶ。指状尺度の検出点と接合点の差は**0.008％**になった。単一の先端合成波の61時刻と保存済みHoudini輪郭110本では旧規則と同一の結果だった。

同じ輪郭を同じ測定規則で比べるため、JSON接合点と検出点の距離を報告・検証する仕組みを加えた。加えて W と呼ぶ幅・面積・張り出し量、S7双方向の差、バックログ側の M6中央値式と10秒保持を**報告専用**で追加した。合成波を横に5％／8％拡大すると W は+5.00％／+8.00％を示したが、原仕様の形状項目は5％拡大を見逃した。Wには閾値を設定していない。

当時の最終自己検証は tests/selftest_measure.py が63項目、tests/selfcheck_tests.py が17組で、いずれも失敗0。後の強化でそれぞれ88項目、38組に増えた。この記録はその前段階の成果であり、現行の成果物が全基準を通ったという意味ではない。元の実行ログと図は results/step1_prepare/measure/ と results/step1_prepare/verify_tests/ などにある。再実行は tools/run_blender.ps1 を経由し、該当の selftest_measure.py と selfcheck_tests.py を指定する。
