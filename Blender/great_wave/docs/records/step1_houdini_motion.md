## 4. 过程中发现并处理的问题

| 问题 | 处理 |
|---|---|
| 用「薄片三角形 + 库」当截面：薄壳的条带内部填不上，追出的轮廓无意义（θ 得到 157°、o = 0） | 改成真正的平面切割 + 奇偶填充（本脚本），薄片只用来核对上缘 |
| 全轮廓早期帧（第 7–15 帧）的 θ 最陡点落在流体块尽头的圆角上 | 加了 `measure_guarded`：最陡点在 X > 4.6 m 且波頂在 3 m 以外时，截掉尽头区重量 θ；原值保留在 json 里，帧带标记 |
| 顶部最后几帧被削平，波頂 X 后跳，o 在末帧跳变 | 不改定义；加标记（F／J）和陪伴量（空洞深度、平顶宽度、水平面片面积） |
| 第一版的「浪后方的谷」被取景下边界（−1 m）截断；第二版 0.1 m 的格子里有的格子没有上表面的点 | 改成直接从切割线取 0.5 m 一格的上包络，不受取景限制；浪前方只取完全在波頭の先之外的格子 |
| 自测一开始把容许的差异像素数定成 20，多边形球的弦误差就有 24 px | 改成「周长的 5％，且边界以外必须为 0」 |
