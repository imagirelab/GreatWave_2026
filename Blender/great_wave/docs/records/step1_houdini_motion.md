# 第1段階記録：Houdini参考の運動読取（2026-09-20）

> この文書は当時の中国語記録を日本語で整理したものです。元の全文は変更前のコミット 0b0178eb9ea6b99ff685d608d557e49068066bb8 で確認できます。数値と判断は当時の記録であり、現在の成果を再検証した結果ではありません。

詳しい解釈と未測定項目は docs/houdini_motion_readout.md、逐フレーム値は target/houdini_motion.json、図と生データは results/step1_prepare/houdini_ref/ にある。スクリプトは src/ref/read_houdini_motion.py、設定は src/ref/read_houdini_motion_params.json。入力の旧パスは G:/research/Wave Simulation/1.abc であり、現在の配置での存在は別途確認が必要。

BlenderでAlembicを読み込み、有効フレーム、静水面、参照波高、波頂基準、固定断面位置を決めた。第1～55フレームについて全側影と固定断面、さらにY方向の9断面を共通測定ライブラリで測った。三段階の処理は measure（Alembic読取）、analyze（区間・比較・JSONと図）、render（外観確認）で、再実行時は tools/run_blender.ps1 に read_houdini_motion.py と --stage measure／analyze／render を渡す。

**測定事実**：24 fpsのうち第1～55フレームが有効で、時間は2.25秒。第56～100フレームは第1フレームの平水面と同一。参照には立ち上がりと張り出しがあるが、巻き込みと停止前の減速は確認できない。固定断面の区間比は72／28、全側影では78／22。第55フレームでも輪郭速度は最大の87～88％である。張り出しを9.5秒へ単純対応させる案には巻き込み0秒という欠落が生じる。

全側影と固定断面は同一ではない。波峰線はY方向へ斜めの三日月形をなし、位置によって高さと張り出し開始時刻が違う。全側影の半高幅2.28 Hに対して一固定断面は1.37 Hである。参照の厚い丸い先端では o(t) と φ(t) が不安定で、空洞深度がより安定した観察量だった。終幕の形状は原画の正解ではない。

この測定はHoudiniキャッシュの**運動参考**を読んだもので、現行の先生が求める「Houdini流体シミュレーションのサーフェスをUnityで実時間表現する」技術が完成した証拠ではない。
