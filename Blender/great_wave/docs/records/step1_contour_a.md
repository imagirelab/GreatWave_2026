# 第1段階記録：基準輪郭候補A（領域法、2026-09-20）

> この文書は当時の中国語記録を日本語で整理したものです。元の全文は変更前のコミット 0b0178eb9ea6b99ff685d608d557e49068066bb8 で確認できます。数値と判断は当時の記録であり、現在の成果を再検証した結果ではありません。

入力は原画 Tsunami_by_hokusai_19th_century.jpg（3859×2594 px）のみ。Houdini形状やCG参考図の形状データは使わなかった。再生成スクリプトは src/contour/method_a_run.py、パラメータは src/contour/method_a_params.json、候補のJSONは target/candidates/a/base_contour.json、数値と図は results/step1_prepare/contour_a/ にある。当時、2回の再実行でJSONのSHA-256は一致した（A796F50B…01CA01）。旧パスは移転前のものなので、現在の配置に合わせて tools/run_blender.ps1 へスクリプトを渡す。

方法は、墨線と爪領域の紙白部分を障壁にした天空の連結領域を求め、浪体の領域境界を追跡するものだった。墨線の細い欠けからの流入を防ぐため天空を3 pxだけ狭めてから拡張し、爪は半径28 pxの円盤による開処理で除いた。開処理後の円弧を爪根の橋とし、原輪郭に沿う traced 部分を4 px、橋を12 pxのガウス幅で平滑化した。手前の波に隠れる内側の弧は可視端で分け、水位 Z＝0へ接線で補完して in_S7=false とした。

爪領域の白い部分を障壁に含めない場合、天空が爪先の欠けから浪体へ流れ込んだ。一方、紙白を全画面で障壁にすると上側の雲を浪体に誤結合したため、白色障壁を x＝1500～2400、y＝250～1200 px に限った。半径28 px時に除かれた主な突起は16個、内接円換算の幅は中央値26.0 px、最大39.8 pxだった。半径20／28／36／44 pxで先端位置はおおむね (2232,791)／(2230,790)／(2230,792)／(2228,799) pxと安定したが、60 px以上では泡の小片まで削れた。

出力の点数は背866、波頭643、内側の弧1284。元の可視墨線からの平滑化偏差は各段の最大でも1.59 px（画面高0.061％）だった。自身のS8は背29.1°、波頭92.9°など15°を大きく超える箇所があり、この候補自体を滑らかな大形の目標とはできない。指状尺度の候補としてBと比較し、差の大きい可視箇所では最終的にBを採った。区間ごとの測定、不確かな位置、裁定の拡大図は原記録と results/step1_prepare/contour_a/metrics.json に残る。
