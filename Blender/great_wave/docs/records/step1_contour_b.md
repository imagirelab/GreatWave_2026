# 第1段階記録：基準輪郭候補B（輪郭追跡法、2026-09-20）

> この文書は当時の中国語記録を日本語で整理したものです。元の全文は変更前のコミット 0b0178eb9ea6b99ff685d608d557e49068066bb8 で確認できます。数値と判断は当時の記録であり、現在の成果を再検証した結果ではありません。

再生成スクリプトは src/contour/method_b_run.py、設定は src/contour/method_b_params.json。候補は target/candidates/b/base_contour.json と、背の左端を別解釈にした base_contour_alt_white_body_outline.json。図と数値は results/step1_prepare/contour_b/ にある。当時の無画面実行は約23秒で、2回の再実行で両JSONのSHA-256が一致した。手動で置いた位置は天空の種点 (2500,300) と追跡終了範囲だけで、波頂や先端を1点ずつ手で合わせていない。

Bは塗り分け領域ではなく、原画の墨線と天空側境界を使う。青色差に加えて明度の黒色トップハットを用い、退色して灰色になった輪郭も検出した。墨線を8 px膨張して隙間からの流入を防ぎ、天空領域から順序付きの外輪郭を追った。爪は半径40 pxの円盤開処理で除き、原輪郭の近くを traced、爪根をまたぐ部分を claw_root_bridge とした。橋は19箇所。可視線は局所輝度の50％交点でサブピクセル補正し、5640点中5558点で補正が成功、平均絶対移動は0.55 pxだった。背・波頭・内側の弧の接合点を共有させ、各段を約2 px間隔へ再標本化した。

当時の主な測定値は、波頂が左38.20％・上8.62％、内側の弧の最深点が左39.56％・上46.94％、爪を除く先端が左57.70％・上30.24％、爪を含む最右点が左59.29％・上33.02％だった。谷の真の水位は手前の波と船に隠れ、原画から確定できない。可視海面の上縁を谷とみなすと波高は64.40％で指定の66％より1.60ポイント低いが、同一の物理量とは確認できない。波頂は幅約5.29％のほぼ平坦な区間であり、最高画素一点の横位置には不確実さがある。

背の画面左端は sky_silhouette と white_body_outline の二通りを出した。前者は左へ上がる別の空側輪郭、後者は白い浪体の輪郭を追う解釈で、左端角度と高さが大きく異なる。この判断は当時未確認だった。後の正式統合では white_body_outline を採用したが、直接の墨線がない部分は構築した線として後に由来フラグを訂正した。候補Bは最終指状尺度輪郭の主な元線になり、さらに半径150 pxの大形輪郭へ発展した。
