## 1. 方法（只用边界，不用填色分类）

1. **墨线掩膜**：`D = B−R`（蓝度）> 8，或者「亮度黑顶帽 closing(L)−L > 45 且局部背景亮度 > 200」。
   后一条是为了抓住**褪色、发灰而不发蓝的轮廓线**（例：x=1815..1835, y≈393，亮度 85–130，D≈0）。
   在下方灰色天空里禁用顶帽（否则亮飞沫点之间的灰色缝隙会被当成墨线，第一次运行时在 x=1715..1760, y=1640..1660 出现过）。
2. **天空连通域 → 有序的外轮廓**：原画的轮廓线有真实的断口（爪尖不闭合，如 x=1937..1945 y=641；x=1899..1904 y=454..467），
   直接漫水会漏进白色浪体。实测：墨线膨胀 0–6 px 都漏，8 px 不漏。做法：天空核 = 离墨线 > 8 px 的区域里从种子漫水，
   再在「非墨线」内测地膨胀 10 px 回到墨线外缘。天空域只用来给出**轮廓线外缘的先后顺序**：沿像素缝（crack）追踪，
   天空在左，从画面左端 x=0 出发 → 背 → 波頂 → 波頭（含爪）→ 波腹下的空洞 → 手前の浪。飞沫白点不是墨线，自动属于天空。
3. **去爪（从浪体一侧滚球）**：对「非天空」做半径 R=40 px 的形态学开运算（精确欧氏距离变换实现）。
   宽度 < 2R = 80 px（画面高 3.1％ = H 的 4.7％）的突出物 = 爪。开运算后的边界上，贴着原轮廓（≤1.5 px）的点标为 `traced`，
   横跨爪根的圆弧标为桥；**桥的两端就是爪根（相邻爪之间的凹点/爪壁切点），桥用两爪根之间的弦代替**（`claw_root_bridge`）。
   偏离原轮廓 ≤3 px 的小桥（噪点、贴边的飞沫点、划痕）并回 `traced`。共 19 处桥。
4. **亚像素**：对 `traced` 点沿局部法线取剖面，天空电平 = 外侧 3–7 px 的中位数，墨线电平 = 内侧 3.5 px 内的最大值，
   取 50％ 电平的穿越点 = **墨线的外缘（朝天空一侧）**。亮天空处用 255−L，灰天空处（局部天空亮度 < 190）用 D。
   5640 个 traced 点中 5558 个成功；平均位移 +0.02 px，平均绝对位移 0.55 px，最大 3.7 px（其后做 9 点中值）。
5. **平滑**：沿弧长高斯，traced σ=3 px，桥 σ=10 px，二者用平滑后的桥指示函数混合。
6. **特征点与分段**：波頂 = 轮廓最高点（用 σ=13 px 的平滑副本取 argmin，抗像素噪声）；波頭の先 = 波頂之后轮廓的最右点；
   内側の弧最深点 = 其后最左点（同样用平滑副本）。背 = 左端→波頂，波頭 = 波頂→波頭の先，内側の弧 = 波頭の先→波頭下面→内側の弧→谷。
   相邻段共用端点；每段按 2 px 等弧长重采样（实际间距 2.0012 / 2.0001 / 1.9998 px，为了两端点精确落在特征点上）。
7. **内側の弧可见部分的终点**：沿法线向浪体内 8/12/16 px 处的 D 中位数不再是蓝色（连续 20 px）→ 终点 (1822.4, 1755.7)。
   再往下 35 px 是一条很细的深色楔子（大浪轮廓与手前の浪轮廓并在一起），方向 36°，比手前の浪的斜边（42°）还平，
   任何光滑延长都会穿过**看得见的天空**，所以这一小段不用。
8. **被遮挡部分的补全**（`completed_occluded`，`in_S7=false`）：二次 Bezier P0–C–P1。P0 = 可见终点，切向 = 最后 300 px 的弦方向
   （水平向下 52.7°），C = 切线与 Z=0（y=1937.72 px）的交点，P1 = C + (f·|C−P0|, 0)，在 Z=0 处水平相切。
   f 取「曲线上没有任何采样点落在可见天空里」的最大值；结果 f=1.0，天空内采样点 0 个。终点 (2189.6, 1937.7) = (+0.418 H, 0)。

## 3. 事实 / 推测 / 建议

### 3.1 需要用户决定的事：「背」在画面左端到底是哪一条线

**事实**
- 背的墨线从波頂往左下走到约 (335, 895) 处**分叉**：
  (a) 上支：左侧蓝色带的上缘（有墨线），先降到 (145, 932) 再**向左上升**，在 y=891.5（上から 34.4％）碰到画面左端；
  (b) 下支：蓝色带的下缘（深蓝直接接白色浪体，没有单独的墨线），是背的墨线**不带折角的光滑延续**，单调下降，在 y=1075.6（41.5％）碰到画面左端。
- 左端斜率：(a) −21°（细）/ −14°（粗）；(b) +11°（细）/ +19°（粗），x=100..200 处 22–29°。说明书 S4 写「左端附近约 25°」。
  (a) 在 x≈300..335（分叉点前）也有 18–30°。
- 「相对天空的剪影」字面上是 (a)；说明书 §7b「原画在左端把背裁掉了，按左端的斜率平滑延伸到静水面」只有在左端向左下降时才说得通，即 (b)。

**推测**：蓝色带更像是大浪后面的海面/下一道涌，而不是大浪浪体；用户量 S4 时用的很可能是 (b)，或者是 (a) 在分叉点附近的一段。我无法从画面断定。

**做法**：`base_contour.json` 按任务书给我的定义（相对天空的剪影）用 (a)；(b) 完整地写在 `base_contour_alt_white_body_outline.json`
（schema 相同，背 883 点，全 traced；在 (338, 902)..(392, 843) 之间用 80 px 从带下缘（内缘）平滑过渡到墨线外缘）。
切换只需改 `method_b_params.json` 的 `back_left_variant`。两条线在 x<392 px 处最大相差 184 px = 画面高 7.1％。**请用户定。**
