目標は半径150 pxの大形 target/base_contour.json。数値と図は results/step1_prepare/proof_swept_contour/ にあり、比較群の一覧は controls_report.json と controls_table.md。構築と試験の詳細なコマンドは元記録に残る。現在の配置では tools/run_blender.ps1 に tests/test_shape.py または test_mesh.py、--build-script tests/fixtures/make_synthetic_wave.py、--build-arg taper=lift_clip、--build-arg profile_json=target/base_contour.json を渡して再検証する。

正式輪郭を25,251頂点、49,506三角形の網目へ掃引して原画解像度3859×2594で評価した。lift_clip 収束では99,675検査点が中央断面内にあり、投影マスクの差は余分0 px、欠損0 px、穴0。旧 clip 方式は空洞の上部を21,267 px塗りつぶし、最大87 px＝画面高3.35％の差を生んだ。

背の接線角を単調化する正対照 back_monotone では、輪郭点の最大移動0.38％、S7背の平均0.076％・95％値0.339％で、S1–S8両段階が合格した。これはS4の不合格が許容S7範囲内で修正できるという検証であり、正式目標が修正済みという意味ではない。

負対照の波頂±3％、幅+5％／+8％、先端±8°は、直接断面折線と網目経由で失敗項目の集合が一致した。判定値の差は位置量0.007％以下、S5方向0.04°以下、S8角0.16°以下だった。ただし**幅+5％は spec 段階のどの項目も失敗させなかった**。報告専用 W は幅+5％／+8％を約+4.97％／+7.97％と読んだ。大形鈍頭では、先端を±8°回しても S5 のφは−3.4°／+1.7°しか変わらず、±5°限度では捕まらなかった。一方、S5位置やS7波頭は変化を示した。G3の厚みは目標形状に由来するため、単なる掃引網目の欠陥ではない。

当時の測定自己検証は63項目・失敗0、試験自己検証は17組・不一致0だった。後の強化では88項目・38組へ増えた。概念検証の「ほぼ合格」を**作品の完全合格と表現しない**。
