## 実施内容

params.json に原画寸法3859×2594 px、初期波高 H＝11 m（許容10.4～13 m）、30 fps／285フレーム、初期時間配分4／3／2.5秒、S8の1％標本間隔、パスを記録した。tests/thresholds.json は S1–S8、M1–M6、G1–G5 の計35検査項目を spec と user_relaxed_5pct の二段階に分けた。後者は当時のユーザーの「誤差率5％以内」の暫定解釈である。

src/gw/bootstrap.py は無画面実行と終了コード、paths.py はパスと閾値、frame.py は画面座標とCAM_print、imgio.py は画像入出力、draw.py と plot.py は検証図の描画を担った。tools/run_blender.ps1 はログと終了コードを保存した。使用環境は当時 Blender 5.2.2 LTS、同梱 Python 3.13 と NumPy で、追加パッケージを用いなかった。

座標の原点、波頂と谷、画枠、CAM_print の具体的な値は docs/legacy_readme_2026-09-20.md にまとめた。基盤ライブラリの自動検証は tests/selftest_foundation.py、出力図は results/step1_prepare/foundation/ にある。原記録で扱った数値・視覚確認の個別結果は変更前コミットを参照すること。この要約だけから現在の制作物の合格は判断できない。
