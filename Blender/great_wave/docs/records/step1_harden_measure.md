# 第1段階記録：測定層の強化（2026-09-20）

> この文書は当時の中国語記録を日本語で整理したものです。元の全文は変更前のコミット 0b0178eb9ea6b99ff685d608d557e49068066bb8 で確認できます。数値と判断は当時の記録であり、現在の成果を再検証した結果ではありません。

対象は src/gw/profile_metrics.py、src/gw/silhouette.py、src/gw/raster.py と tests/selftest_measure.py。tests/thresholds.json の値・比較方法・二段階、基準輪郭の点、カメラは変更していない。審査で見つかった「測定時に黙って捨てられる」六種類の状態を数値化し、戻り値に含めた。S1–S8 の元の判定量は変更せず、新規の形状量は報告専用とした。

非有限頂点、削除した三角形・孤立成分、モデル自身の谷水位、指定から変えた測定パラメータを報告する。幅だけを絶対高さで切ると「横に5％拡大、縦に1.9％縮小」の形状変化を逆向きに読む場合があるため、各輪郭の自身の波高で規格化した shape 系を追加した。正式輪郭の0.5 hの背は画面左端で切られるので、その縦横比は比較に使えず、0.75 h の比を併記する。

この複合変形について、元の W.z75 の幅は−5.22％と表示された一方、新しい0.75 hの縦横比は約+8.1％だった。符号付き S7 偏差も追加したが、平均だけでは正負が相殺されるため5％点・95％点を併記する。報告専用の折線頂点窓角では正式輪郭自身が19.1°を示したため、15°をそのまま新閾値にできない。443点掃引断面に入れた20°の逆曲率折れは実際の折線では12.5°の転角となり、15°ルールだけでは検出できなかった。

当時の最終自己検証は tests/selftest_measure.py が88項目・失敗0、tests/selfcheck_tests.py が17組・不一致0。後者はこの記録時点の数で、テスト層の強化後には38組になった。数値は results/step1_prepare/harden_measure/、自己検証報告は results/step1_prepare/measure/selftest_measure_report.json に保存した。再実行は tools/run_blender.ps1 に tests/selftest_measure.py を渡す。

**残る限界**：投影で主体に重なる別網目は孤立成分として見つからない。谷水位の最低点方式は局所的な海面上昇を見逃し得る。頂点窓角は頂点密度に依存する。新しい報告値を判定へ昇格させるには、目標自体の値と検出能力を検討して閾値を決める必要がある。
