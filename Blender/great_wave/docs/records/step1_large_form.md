## 2. 做了什么

1. 读了说明书、裁决报告和各份记录，看了已有的放大图。
2. 写了 `build_large_form.py`：指状尺度轮廓 → 闭合区域（两端沿端点切线延长，远处闭合，浪体在内）→ 全分辨率栅格 → 半径 r 的圆盘**先闭后开**（精确欧氏距离变换）→ 在最后一次距离场的等值面上取亚像素边界 → 1 px 重采样 + σ＝0.5％ 的弧长高斯 → 与原线比较：偏离 < 0.15％ 且原线自身转角不超过球的转角的地方保留**原线**，其余用正则化后的线，接缝用 2％ 长的 smoothstep 过渡 → 标记、地标、三段、2 px 重采样、各项测量、JSON、图。
3. 两种顺序（先闭后开 / 先开后闭）× r＝100 / 120 / 135 / 150 px 都算了；另外试了 r＝165 / 180 / 200（稳定性）和后平滑 σ＝0.25 / 0.5 / 1％。
4. 按编排者给的规则自动选正式 r：候选 100 / 120 / 150 里自身 S8 最大值 ≤ 11° 的最小者 → **r＝150 px**。
5. 逐张看了全部输出图（决策图、全浪叠加、波頭三种半径、先端放大、两种顺序、波頂/台阶、竖直面、腋部、下面、左端两种读法、内側の弧下端、背中段、各变体 S8 曲线、带符号转角与偏差曲线、「原线保留在哪里」诊断图），看图之后改过 4 次：顺序从先开后闭改成先闭后开；起点改为严格落在 x＝0；标记加最短连续长度；决策图排版。
6. 用测试脚本把正式轮廓扫成网格跑了一次 `tests/test_shape.py`（`results/20260920_082807_shape_swept_large_form_r150/`）。

## 4. 没有过 / 需要别人知道的项

1. **S4 `flattens_towards_crest` 对任何半径都是 false**（回升 16.6°）。原因不是波頭：手绘的背本身有起伏（实测：2％ 弦斜率相对其 σ＝3％ 平滑趋势偏 −9.4…+13.0°，均方根 4.7°；背到自己的 σ＝3％ 平滑副本的距离 平均 0.13％ / p95 0.27％ / 最大 0.29％），最大的一处是波頂平台左端的小坡（x 1320→1380，y 243.8→225.6，即 60 px 内升 18 px＝0.70％）。这些起伏的曲率半径 > 150 px，S8 不要求去掉；按编排者「偏离 < 0.15％ 的地方保留原线」的规则它们被保留。模型可以在 S7 的 1％ 之内把它们抹平而通过这一项；对基準輪郭自身这一项只能报告。高斯低通 σ 2％ 也还有 4.0°（限 2°）。
2. **r＝100 自身 S8＝15.2°**（球的设计值 14.86°＋栅格噪声约 0.4°），不满足 S8；r＝120：12.7°；r＝135：11.5°；**r＝150：10.3°**。编排者的目标「≤ 约 11°」只有 150 满足。
3. 把正式轮廓扫成网格跑 `test_shape.py`：spec 档不过 3 项——(a) `S4.flattens_towards_crest`（同上，目标自己也不过）；(b) `S7.inner_arc.p95`＝3.16％、(c) `S8`＝65.0°，都在 (1565–1701, 995) 一条水平直线上：这是合成浪夹具的 `clip` 收束把空洞顶部填平造成的（空洞的顶在腋部最高 (1701, 907)，波頭下面向右下降到 (2036, 995)），不是轮廓的问题。其余全部通过：S1 dx −0.84 / dz +0.03，S2 0.64，S3 +0.03，S5 位置 0.14％ / 朝向 −1.0°，S6 56.82％，S7 背 0.006 / 0.017、波頭 0.006 / 0.013。**目标自检**（基準輪郭对自己）现在只剩 `S4.flattens` 一项不过（之前 9 项）。
4. 测试库「JSON 接缝 vs 检测」：正式文件 波頂 0.123％、先端 0.001％、最深点 0％，都在 0.2％ 之内。其它半径的波頂是 0.19–0.30％：波頂是宽约 100 px、平到 ±0.5 px 的平台，「σ＝0.5％ 平滑后取最高」（JSON，沿用裁决的规则）和「水平集中点外推」（测试库）都落在平台里、但位置由亚像素差决定，相差 3–8 px，只有 dx，dz＝0.00％。先端和最深点在所有变体上都一致（≤ 0.001％）。

## 5. 向其他模块报告的事

- **顺序**：先开后闭不稳定。实测指状尺度的波頭有两处「细颈」：先端瓣在天空小袋 (2127, 770) 与右侧面凹口 (2173, 881) 之间只有 120 px（7.0％ H）；波頭下块整体通过「竖直面下凹角一侧 (1910, 634) ↔ 波頭下面第一个凹口 (1774, 883)」之间 284 px（16.6％ H）的颈与浪体相连。球的直径超过颈宽，开运算就把颈外的部分整块去掉：先端 x＝2169（r 100，先端瓣没了）→ 2110（120）→ 2099（135）→ **1920（150，下块整个没了）**，波頭偏差到 12％。先闭后开：2197 / 2194 / 2194 / 2193，r＝165 仍是 2188，r＝180 开始后退（2165），r＝200 才塌（2053）。
- **波頭最下面一瓣**（最低点 (2086, 1091)；实测宽度：y＝1000 处 158 px、1040 处 120 px、1080 处 46 px）比 2 × 99＝198 px 窄，**任何满足 S8 的 r 都会把它去掉**（r＝100 时也偏 3.4％）。它和先端瓣右上角（被削 2.2％）是以后放爪 / 泡沫时要从 `target/base_contour_finger_scale.json` 补回来的部分。
- 说明书 G3（縁 ≤ 3％ H）与原画的关系见报告第 11.7 节。
- 空洞的顶不是单调的（腋部最高），§7a 的收束方案要注意不要把它填平（上面第 4.3 项）。
- `results/step1_prepare/contour_large_form/trial_*` 是我的试跑输出，可以忽略（没有删除任何文件）。`results/20260920_082807_shape_swept_large_form_r150/` 是上面第 4.3 项那次测试的输出。
