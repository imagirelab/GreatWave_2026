# 任务：在 Blender 里重新做一道动态的大浪（《神奈川沖浪裏》）

## 1. 目标

在 Blender 里从头做一道动态的大浪：从平缓的涌立起、张出、卷入，最后静止在原画那一瞬间的形状。目前只做画中最大的那道浪。

- **方法任意。** 用什么手段做由你决定（§8）。
- **不沿用之前 Houdini 的制作流程。** Houdini 的模拟结果不作为网格的来源，也不拿它的几何去变形；它只是看运动用的参考（§6）。
- **终幕的形状**必须满足 §5 的原画实测指标。
- **动态**参考我之前在 Houdini 里模拟的大浪。那段运动我是满意的。

之前 Houdini 版本的问题，也就是这次要解决的：终幕在原画对照视点下，浪体太宽、不够高，轮廓与原画不匹配。

## 2. 范围

- 做：大浪的浪体，即「大波の大形」＝去掉爪・縞・飛沫之后的大浪的形，以及它的动态。
- 不做：爪形波頭、飞沫和白水粒子、縞和上色、材质、手前の浪、右側の浪、船、富士山、周围的 FFT 海面、Unity 导入。

## 4. 术语、坐标、尺度

术语与バックログ「定義」一致：

- 波頂：大浪的最高点。
- 背：从画面左端到波頂的外侧轮廓线。
- 波頭：从波頂向船の側张出的部分。波頭の先：基準輪郭上，波頭最靠右的点。
- 波腹：波頭下方的内侧面。内側の弧：从波頭下方到谷的内侧轮廓线。
- 谷：波頭下方的海面。裾：大浪接到周围海面的地方。
- 船の側：原画对照视点下的右方，也就是大浪卷入的方向。
- 基準輪郭：在原画的大浪上去掉爪和飞沫、把爪的根部连起来得到的轮廓线。
- 原画対照視点：与原画同构图的观察视点。終幕（静止時）：大浪停住的那一帧。

坐标（Blender，1 单位＝1 m，Z 向上）：

- +X＝船の側（原画的右）。+Y＝沿波峰线的方向，即原画的纵深方向。Z＝0 是谷的水面。
- 终幕时波頂位于 X＝0 的铅垂线上，高度 Z＝H。
- H＝谷から波頂の高さ，默认 11 m，做成参数 `WAVE_HEIGHT_M`。允许范围 10.4–13 m（バックログ「大きさの設定」：押送船全長 13 m 的 0.8–1 倍）。

原画画面到场景的换算：

- 画面高＝H ÷ 0.66＝1.5152 H；画面宽＝2.2540 H。
- 画面左端 X＝−0.861 H，右端 X＝+1.393 H，上端 Z＝+1.132 H，下端 Z＝−0.383 H。
- 画面高的 1％＝0.01515 H（H＝11 m 时 0.167 m）；2％＝0.0303 H（0.333 m）。

判定用相机 `CAM_print`：正交相机，视线沿 +Y，画幅比 3859:2594，取景范围就是上面的左右上下端。

## 5. 终幕形状的指标

位置的 ％ 是原画基准图上的实测（左から・上から）；括号里是换算后的 (X, Z)。容许误差沿用バックログ的初期比较目标。

| 编号 | 项目 | 目标值 | 容许误差 |
|---|---|---|---|
| S1 | 波頂の位置 | 左 38.2％・上 8.7％ → (0, 1.000 H) | 上下、左右各 ≤ 画面高的 2％ |
| S2 | 内側の弧の最深点 | 左 39.5％・上 46.3％ → (+0.029 H, 0.430 H)。几乎在波頂正下方、浪高的中间 | ≤ 画面高的 2％ |
| S3 | 谷から波頂の高さ | 画面高的 66％（谷的水面在上から约 74.7％） | ±2％ |
| S4 | 背の傾き | 左端附近约 25°，中段最大约 47°，波頂之前约 8° | 以 S7 为准；另外报告这三处的实测倾角，并检查：中段最陡，向波頂逐渐变缓，顶部是圆的、没有折角 |
| S5 | 波頭の先（不含爪） | 位置和朝向从基準輪郭上量出 | 位置 ≤ 画面高的 2％；朝向 ±5° |
| S6 | 含爪的最右点（只作外边界） | 左 59.2％・上 33.0％ → (+0.473 H, 0.632 H)。由它算出：张出＝浪高的 47％，波頂→该点的方向＝水平向下 38° | 浪体最靠右的点必须在它的左侧 |
| S7 | 轮廓的一致 | 背、波頭、内側の弧三段，分别与基準輪郭比较 | 每段平均偏差 ≤ 画面高的 1％，95％ 的点 ≤ 2％ |
| S8 | 轮廓的平滑 | 沿轮廓相邻采样点的切线方向差 ＜ 15° | 采样间距取画面高的 1％（初始设定，写进参数） |

注意：

- **S5 和 S6 不是一回事。** 59.2％／33.0％ 是含爪的最右点，张出 47％ 和 38° 都是由它算出来的。这次的浪体不含爪，所以浪体的波頭の先应该落在这个点的左上方，给之后的爪留出长度。不要把浪体拉到 59.2％。
- 内側の弧在测试里＝从 `CAM_print` 看过去，空洞里透出背景的那片区域的左边界。如果三维形态让空洞被近处或远处的浪体挡住，S2 和 S7 会失败。这是对三维形态的约束，不是测试的问题。
- 基準輪郭上被手前の浪或船挡住、由你补全的区间要标记出来，不计入 S7 的误差统计。
- §5 的实测值是之前用像素分析量的，没有经过第二次独立核对。做基準輪郭时把 S1、S2、S3、S4、S6 重新量一遍，相差超过画面高的 1％ 就列出来告诉我。

## 6. 动态的要求

**6.1 参考。** Houdini 那段运动里要参考的是：立起、张出、卷入各占多长的节奏；形变的先后顺序；停止前的减速。只参考运动，不参考它的终幕形状。先从参考素材里把运动读出来：量得了的话，逐帧或抽帧量出 6.2 的几个量，画成曲线；量不了的话，做成连续帧图，再用文字写出你读到的节奏和顺序。把读到的结果给我看，作为你设计运动的依据。

**6.2 描述运动用的量。** 在 `CAM_print` 的轮廓上逐帧测：

- h(t)：波頂相对静水面的高度
- x_c(t)：波頂的水平位置
- θ(t)：前面（船の側的面）最陡处的倾角
- o(t)：张出量＝波頭の先超出波頂铅垂线、向船の側伸出的水平距离
- φ(t)：波頭の先的朝向（相对水平）

**6.3 验收。**

| 编号 | 条件 |
|---|---|
| M1 | 起始帧是前面最大倾角 ＜ 30° 的涌 |
| M2 | 高まる区間：h 单调上升，一直升到張り出す区間开始；θ 从 ≤ 30° 连续变到 ≥ 80° |
| M3 | 張り出す区間：波頭の先越过波頂的铅垂线、向船の側前进；o 单调增加；h 的下降不超过 5％ |
| M4 | 巻き込む区間：φ 单调向下，最后连续地接到终幕形状 |
| M5 | 停止：停止前 1 秒内逐渐减速，停止瞬间轮廓的移动速度 ≤ 全程最大速度的 20％；到达终幕时位置和形状不跳变；静止之后形状不变 |
| M6 | 全程：任意相邻两帧之间轮廓的最大位移 ＜ 其前后帧位移的 3 倍（没有突跳） |

**6.4 与参考的对比。** 做完后，把你的动画和 Houdini 参考并排：连续帧图，加上 6.2 的曲线对比。这一部分由我目视判断，不设数值阈值。

**6.5 时长。** 30 fps。バックログ的初期设定是 高まる 4 s、張り出す 3 s、巻き込む 2.5 s，共 9.5 s＝285 帧。总长取 9.5 s，三个区间的比例参考 Houdini 的节奏；与 4／3／2.5 s 差多少报告给我，要不要改由我决定。

## 7. 交付物的约束

这些是对结果的要求，不限制你用什么方法得到它。

- **最终交付的网格是固定拓扑**：全程顶点数、面、UV 都不变，同一个顶点在相邻帧之间的运动连续。原因：之后縞的贴图要用这张网格的 UV，爪要挂在它的顶点上，还要导出到 Unity 逐帧播放。如果你选的方法天然产生逐帧变化的拓扑（比如流体模拟），要在方法说明里写清楚怎样得到固定拓扑的版本；注意垂直投影在悬空的卷浪处会失败。
- UV：U 沿截面轮廓（背的裾 → 波頂 → 波頭の先 → 波腹 → 谷），V 沿波峰线。
- 顶点组 `crest_rim`：波頭の縁那一圈顶点，之后爪从这里长出。
- 波頭の縁的厚度 ≤ 浪高的 3％（バックログ里的暂定值）。
- 裾：网格外缘在所有帧都落在静水面上，段差 ＜ 浪高的 1％。
- 参考：现有 Unity 缓存是 85,120 顶点。新网格控制在同一量级，具体数目由你提议。

**原画给不出、要由我来定的量。** 都做成参数，先给默认值和对比图，不要默默决定：

- a. 沿波峰线方向（纵深）的形状：同一个截面延续多长、两端怎样收束。バックログ里这一项还是〔要決定〕，条件是从船上左右看时大浪的端不进入视野。至少给两个方案。
- b. 画面左端以外的背：原画在左端把背裁掉了。按左端的斜率平滑延伸到静水面，延伸长度做成参数。
- c. 被手前の浪和船挡住的部分（波腹下部、谷）：平滑补全。
- d. 谷的水面与静水面的高度差：默认 0。
- e. 波峰线在俯视下是直线还是弧线：默认直线。

## 8. 方法

**方法任意。** 程序化或参数化的建模加动画（Geometry Nodes、用 Python 生成网格、曲线和修改器、形变器、Shape Key 等）、物理模拟（Mantaflow、FLIP Fluids 等）、或者两者混合，都可以。选择的标准只有一个：能不能通过 §5、§6、§7。

动手之前，用半页以内说明：

- 你选的方法，以及你考虑过但没选的方法和理由；
- 它怎样保证终幕通过 §5，特别是 S7 的 1％／2％；
- 它怎样得到 §6 的运动；
- 它怎样满足 §7 的固定拓扑；
- 每一步的估时。

供你判断用的事实：

- 我之前用 Houdini 的 FLIP 模拟做了大约一个月，结果是运动合格，终幕形状没能对上原画。
- 每一项工作要控制在 5 小时以内，含计算和等待时间。整个作品的制作期限是 2026/10/29，大浪只是其中一部分。
- 所有形状都要由脚本和参数生成，能够重建；不做手工雕刻或逐点手调。
