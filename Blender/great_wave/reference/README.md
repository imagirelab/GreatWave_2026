# Painting references

`Tsunami_by_hokusai_clean.jpg` is the unmarked 3859 × 2594 reference used for rendering and visual checks. Source: [Wikimedia Commons, *Tsunami by hokusai 19th century.jpg*](https://commons.wikimedia.org/wiki/File:Tsunami_by_hokusai_19th_century.jpg), a faithful reproduction of a public-domain print. SHA-256: `30C170260DE393F51BD592ADACC6F0714B60F157C09744E9C5B6D46E6A613718`.

`Tsunami_by_hokusai_19th_century.jpg` is the earlier local copy with blue markup. It is retained because the traced `target/base_contour.json` and its provenance were developed against that copy. It is **not** used as the current style texture. SHA-256: `73F98277F3D62D324C9DCF472B8CA7A4F704055C385B37EA6DE189CB5C66D5EF`.

Both images have the same pixel dimensions. The separate contour data remains the geometric target; switching the painting image does not alter that data.
