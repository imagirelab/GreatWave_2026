# Whitewater — 白波

白波を主波面とは別に造形・アニメーション化するための作業区分です。現在、`Blender/great_wave/` に主波面とは別の白波と波の先端部の試作があります。[原画視点](../Blender/great_wave/deliverables/great_wave_motion_print_reference.mp4)および[斜め視点](../Blender/great_wave/deliverables/great_wave_motion_3d.mp4)の動画で動きを確認できます。実装と検証の範囲は [段階記録](../Blender/great_wave/docs/milestones/2026-09-24_foam_and_review_assets.md) に記載しています。

この試作は手作業で制御した造形・アニメーションであり、流体シミュレーションによる白波ではありません。HMD での見え方、リアルタイム性能、主波面との物理的な整合性は未検証です。
