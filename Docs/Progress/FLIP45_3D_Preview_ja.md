## 1. 条件

| 項目 | 値 | 理由・出典 |
| --- | --- | --- |
| 借りた計算 | Fochesato・Grilli・Dias 2007（Wave Motion 44, 395–416）の基準の例。3D の高次の境界要素法（BEM、空気と粘りなし） | 作品と同じ桁（水深 20 m、波高 10.8 m）で、向きの集まりだけで前へ巻いた答えがある【文献】 |
| 水深・周期 | 20 m の平らな海底、周期 7.004 s（波長 72.0 m、kh 1.75） | 論文のまま【文献・計算】 |
| 成分 | 30 成分を −45〜45° に一様、板の振れ 0.200 m、波の振幅 0.185〜0.262 m、和 6.29 m。全部の山が (250 m, 0) でそろう位相 | 論文のまま【文献】。和 6.29 m が線形の焦点の高さを決める（高さの元は入口で選んでいる） |
| 入口 | 論文の水槽（幅 600 m、横は壁）の線形の場を、深さごとの表にして、入口の帯（x 0〜36 m）と横の帯（y 72〜108 m、x 200 m まで）で格子の流速を寄せる。入口の帯だけ利得 1.1323 | 利得は、帯が直角の波を目標の 0.883 倍しか起こさないのを補う造波の較正で、巻く結果を見る前に煙の試しだけで決めた【測定】 |

| 領域 | x 0〜340 m（出口の帯 304〜340 m）、y 0〜108 m（y = 0 を対称の面として半分の幅を解く）、縦 −20〜+16 m | 論文も y = 0 と底に像の方法を使い、半分を解いた【文献】 |

| 時間 | t −2 → 69 s、1,705 コマ（24 コマ/s） | 巻き始め（論文 48.2 s）と着水の後まで |

## 4. 限り（確かでない事）

1. **粗い**：粒子 0.5 m（格子 1 m）。同じ周期・水深の平らな波で、振幅の減りは 1 波長あたり 5.5 %（粒子 0.25 m で 1.1 %）、速さは線形の 0.962 倍【測定：煙の試し S2b】。V1 の伝わる間の減り（N10 0.954）も同じ桁。頂の高さと巻き始めの場所・時刻は、この減りで大きく動く【推測】。
2. **唇は解けていない**：唇は格子 1 個前後で、記録の読み方で量が 2 倍以上変わる。
3. **水の量の増え**：閉じた箱の平均の水面が、波が入ると 0.13〜0.17 m 上がった（水の体積 +1.1 %、粒子の数 +12 %）。入口の帯が先に上がり、群の速さ（6.2 m/s）より速い 18.5 m/s で内へ広がったので、入口の帯の流速の寄せ方が元の見込み【測定・推測】。分けてはいない。
4. **入口**：利得 1.1323 を入口の帯だけに掛けた。煙の試しで、斜めの組では目標より 4〜10 % 高くなった（計画の判定は外れ、利得は変えていない）【測定】。立ち上げの式と板の振れの符号は論文に書かれておらず、論文の頂が線形の頂より 31 m 先にいる理由の大部分（計画の読みで 3 分の 2）は分かっていない【文献・計算】。巻き始めが論文より遅い・先なのは、この入力の不明と細かさの両方の分がありうる【推測】。
5. **APIC の y = 0 の偏り**：V1 は APIC の受け渡しで、y = 0 を箱の壁（対称の面）にした。後の FLIP46・FLIP47 の試しで、APIC は箱の小さい側の壁（y = 0）へ向かう偽の横流れを作り、y = 0 の層の頂を遅らせ低くすることが分かった（FLIP46 の粒子 0.5 m で 3 s に 0.4 m 遅れ・0.1 m 低い）【測定：FLIP46・FLIP47】。V1 の y = 0 の断面の値にも同じ偏りが入っている恐れがあるが、V1 では確かめていない【推測】。3D の次の計算は FLIP の受け渡しにする。
6. **再現の判定ではない**：計画どおり、論文との比べは粗い下見の記録。本番 M1（粒子 0.25 m）で判定する。
7. **Unity**：面の書き出しの形と読み戻しは煙の試しで確かめたが、Unity での読み込みは確かめていない。

## 5. 現在地と次

- 現在地：V1 は終わり、関門 (a)(b)(d) は入った。巻き始めの時刻が論文の ±5 % の外なので、計画の決まりでは、合意の後、M1 の前に立ち上げの感度の計算 V3 を走らせる。本番の時間の見込みは並び B の L1 で M1 が 11.4〜28.3 時間【推測】。
- 次：指導教員の返事（2D の海底の近さを認めていただけるか）を受けて、3D を平らな海底の再現（M1）から始めるか、FLIP47 で選んだ海底で始めるかを決める。どちらでも速度の受け渡しは FLIP にする。
