## 1. 何を作ったか

| 物 | 中身 |
| --- | --- |
| 目標の計算【文献】 | Guyenne & Grilli 2006（J. Fluid Mech. 547, 361–388）。孤立波（H0/h0 0.6）が、真ん中の勾配 1:15・横に sech²(k y') で低くなる尾根を上って 3D で巻く。k 0.25 の表 1：崩れの時刻 t' 7.890（10.39 s）、x' 16.093（273.5 m）、zB 0.706 h0（12.0 m）、hB 0.275 h0、zB/hB 2.567。2D（勾配 0.067）は 2.282 |
| 厳密な孤立波の解き手 | `g46_solitary.py`（numpy だけ）。Clamond & Dutykh 2013 の書き方（等角写像と Petviashvili の反復）。a/h0 0.6 で F = c/√(g h0) 1.2499911（c 16.140 m/s、h0 17 m）。文献の F と a の対 3 つを 10⁻¹³ の桁で再現、水面の条件の残り 7.6 × 10⁻¹⁴【計算】 |
| 場面 | [Houdini/FLIP46/g46_tank.hiplc](../../Houdini/FLIP46/)。箱 x 0〜323 m、y 0〜68 m（y = 0 は対称の面）、縦 −17〜+17 m。尾根は x 88.825 m から、海底は全部 SDF の壁。帯なし（初めの波だけ）。粒子は海底から孤立波の水面まで置き、解の流速を持たせる |
| 走らせる・読む・動画の道具 | [Tools/GWWaveGen/flip46](../../Tools/GWWaveGen/flip46/)（`g46_run.py`・`g46_chain.py`・`g46_analyze.py`・`g46_video.py` ほか）。読みは「前の面に初めて縦の接線が出たコマ」の t・x・zB・hB を表 1 と ±5 % で比べ、原画の物差し（STUDY52）の量も出す。答えの分かった合成の記録で、読みが真の時刻の 0〜2 コマ遅れ（±5 % の時間 0.52 s より小さい）で出ることを確かめた【測定】 |
| 設定 | P05（粒子 0.5 m、0〜15 s、361 コマ）、P025（0.25 m）、P05_FLIP（FLIP の受け渡し）、P05_GN（比べに GN の孤立波） |

## 3. 分かっている問題

1. **APIC の y = 0 の壁の偏り**【測定】：横に一様のはずの平らな海底の孤立波で、対称の面 y = 0 の近くだけに y = 0 へ向かう偽の横流れが出る（粒子 1.0 m の 4 s で平均 −0.15 m/s・最大 −0.33 m/s、粒子 0.5 m の 3 s で平均 −0.04 m/s・最大 −0.085 m/s）。外の壁 y = 68 m には出ない。y = 0 の層の頂は遅れて低い（粒子 0.5 m の 3 s で 0.4 m 遅れ・0.1 m 低い）。前処理を変えても・粒子の補いを止めても同じで、速度の受け渡しを FLIP にすると消える。論文との比べは y = 0 の断面なので、P05 を FLIP でも走らせる設定 P05_FLIP を置いた。後の FLIP47 の 2D の板でも同じ偏りが見つかり、FLIP の受け渡しを使うことにした。
2. **粒子 0.25 m で 3 回に 1 回落ちた**【測定】：最初の時間の試し（粒子 2,014 万）で、途中保存を書き始めて 26 MB の所で hython が落ちた（Segmentation fault）。同じ設定のやり直しと、途中保存だけの試しは最後まで書けた。わけは分からない（その時は計算機が混んでいた見込み【推測】）。
3. **zB が高く出る向き**【測定・推測】：波の前の静かな所の水面の読みが時間とともに 0.03〜0.05 m 上がる（水の量は変わらないので、粒子から作る水面のずれ）。崩れの頃の zB は +1〜3.5 % 高く出うる。zB/hB が +2〜5 % の時は、この偏りの幅の中と読む。
4. **論文の着水の時刻はない**：境界要素法は巻き始めの少し後で止まる【文献】。着水の比べはできない。

## 4. この場面の使いどころ【推測】

- [差の診断](../Research/Gap_Diagnosis_20261012_ja.md) §4 で、原画の形は「急に浅くなる海底の上で水深に限られて巻く」部類と読んだ。この論文の 3D の巻きは、その部類の答えのある計算（zB/hB 2.57、頂が崩れる所の水深の 2.6 倍）である。
- 論文の著者は、着く直前の噴流の近くの流れは 2D と 3D でほぼ同じ（図 11）と書いている【文献】。3D で横に短い頂が加わっても、断面の巻き方は 2D の海底の実験（FLIP47）と大きくは変わらない見込み。
