# 14：船上・側面・背面からの立体確認

日付：2026-09-24。結果：同一の3Dシーンに4視点を保存し、Unityで実描画した。船上と原画比較のカメラは別物で、HMD試験ではない。

船上の眼の位置は、読み込んだ `Boat_Deck_Planks` の実メッシュへ上からレイを当てて決定した。甲板の上り勾配を含む表面を測り、その1.20m上を着座眼高とした。実測甲板のワールド高さ約0.1565m、眼高約1.3565m。主波の境界の外に眼があり、船上から波・白波・他の船が見える。船縁が画面下に入り、波の全体像は見回して確かめる構成。

富士の頂点と近くの波上の検討点に対して、ワールドX方向0.6mの基線による幾何的な角度視差を比較した。富士約0.082°、近傍約1.52°。投影画像の移動や頭部追跡の測定ではない。対象点・基線方向・カメラ値はJSONに保存した。

各画像はUnity Editorの1280×720オフスクリーン描画。側面・背面から閉じた厚い波と奥行き変化を確認できる一方、端面が硬く、前景が角張り、泡が少ない。これらは粗い静止形状の制約であり、物理・美学的な完成判定ではない。

PC表示には視点切替、見回し、リセット、停止を用意した。15の実行ビルドで入力イベントと記録を検証する。物理キーボード・マウスによる利用者操作、HMDの両眼・頭部追跡・快適性は未確認。
