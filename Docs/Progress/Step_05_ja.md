# 05：第一完成版とM0の判定基準

日付：2026-09-24／結果：制作範囲と確認表を固定。下記は合格条件であり、実装完了の報告ではない。

## 第一完成版の仮仕様

最終的な第一完成版はPC接続VR・着座・船一隻とし、短い単発の主役波と独立した白波モデルを見る体験を目指す。まず鑑賞を成立させ、その後に制限された水域の前進・減速・旋回を加える。全体60〜90秒は後続工程の仮目標であり、一続きの流体計算時間を意味しない。物理検証の時間倍率は1とする。

今回の制作上限はM0の番号01〜10。波・白波・浮力・操船・富士の構図・浮世絵シェーダーは実装しない。仮の静止船と水平な平面、1m基準と方位で、単位・表示・入力・ビルドの基礎を確かめる。平面は海の流体検証結果と呼ばない。
