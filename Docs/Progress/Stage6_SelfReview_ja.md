## 0. 結論

**段階6 は閉じる（CLOSE）。ただし条件付きで、満たしていないものを下に明記する。**

1. **段階の出口の 3 項目は、PC の描画と Mock の両眼で満たした**（第 2 節）。
   - 白波が水面と無関係に漂わない：**満たす**。白の帯はシートの色、爪は根元がシートの上、飛沫は唇の頂点から出て空中を飛ぶ。自分の動画の検査で、水の面に触れない爪の塊は 421 コマ × 2 視点で 0。
   - 輪郭がフレームごとに飛ばない：**おおむね満たす**。自分の動画の検査で、動いている間に跳びとして目立つコマの組はない（新しい縁の比は最大 1.26）。例外は段階5 からの S5-1（コマ 184→185、仮置きの右の波の色面）で、段階6 の中身ではない。爪の帯の断面の小さな段（C072 など、原画視点で最大 2.2 px）は記録どおり残る。
   - 爪の房が両眼で同じ位置に見える：**Mock で満たす**。片目にしかない房は 0。視差の分だけずらすと、爪の画素の 98.3〜99.96% が相手の目の爪から 1 px 以内。**HMD（PS VR2）では確かめていない（保留）。**
2. **各番号の最小の受入は、31〜35 のすべてで満たした**（第 3 節）。設計32 は修正01 で必須の指摘 3 つを直した後。設計35 の A1（3 版の違いが動画で分かる）は、白の帯を切った段でだけはっきり分かり、弱い。
3. **回帰（計画 §2.0）**（第 4 節。評価器を自分で回し直して、記録の値を再現した）：
   - 輪郭は後退なし。78／130／131・132 σ12 は変わらず、72 σ24 p95 は 4.0075 → 3.8423 px で、この読みでは 4 px を下回った。
   - **色区は、爪を色区 ID に入れると 133・134・267 が合格 → 不合格になる。** 設計34 は「爪の層を除いて測る」読みで閉じた。段階として、これは「後退なし」ではない。段階5確認 §6.3 と同じく、規則を損切りで上書きしたと記録し、設計36 で戻すことを条件にする（第 4.2 節）。
   - CP1／26修正01 に対する後退（段階5確認 §6.3）は、段階6 では増えも減りもしない。
4. **満たしていないもの・弱いもの**（閉じても満たしたことにならない）：
   - **原画視点で、3D の爪がほとんど読めない。** 爪の白い上面は白の帯に溶け、淡い水色の細い弧が焼き込みの模様の上に重なって、模様の乱れに見える。原画視点で爪の房に見えているのは、ほとんど 29修正01 の焼き込みの色面の模様である。座席 v1 でも、白の帯の上では同じく溶ける（第 7 節の F6-1）。
   - 輪郭の細部込みの値は、爪で良くなったがまだ 4 px を超える：132 最大 5.9472 → 5.2998 px、72 p95 8.7546 → 7.8009 px（Unity の画像で再現）。
   - 飛沫は 186 個で、計画の 2〜3 千個より少ない。放出点の 63／186 が、終態が白でない頂点にある。
   - 設計35 の V2（軽量版）は、普通の読みでは V1 とほとんど違わない（波頭で 0.10〜0.15%）。
   - 右側の爪（C129〜C153）はシートに結び付けておらず、作っていない（計画どおり、ブラッシュアップの最後）。
5. **閉じる理由**：段階の出口は満たし、各番号の最小の受入も満たした。満たしていないものは、どれも次の段階の番号（設計36・38・39・40）か仕上げ31〜35・28・30 に行き先がある（第 8 節）。Q24・Q26 は止まらずに進めることを求めている。爪の見え方と色区の後退は、設計36（限定色）・設計38（輪郭線）の中身そのもので、段階6 に留まって直すと番号の順を崩す。
6. **既定の版は V1（一覧どおり）のまま**（設計35 の決定を、この確認でも変えない。第 5 節）。
7. **閉じるコミット（`段階6確認：`）に含めるもの**（第 9 節）：この記録と、`Docs/Evidence/Stage6/` の図 3 枚と `s6_checks.json`。

- 計画 §2.0 の規則は「CP1 と 26修正01 で合格した項目を後退させない。後退したら統合しない」。爪を色区 ID に入れた両側の読み（29修正01 が採った読み）では、133・134・267 が合格から不合格になる。設計34 は「色区は爪の層を除いたシートの色で測る」読みで閉じた。**段階6 として「回帰なし」とは書かない。**
