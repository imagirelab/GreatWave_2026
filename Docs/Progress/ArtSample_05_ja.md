## 8. 利用者に選んでほしいこと

1. **形 A と形 B のどちらの方向がよいか**（または両方を合わせる：形 B の原画視点の並びに、形 A の ③ の体を持ち込む。批評の勧め）。いちばん見てほしい図は `as05_2b_clay_turntable.png`・`as05_2c_layers.png`（形だけ）と `as05_1a_painting_view.png`（原画視点）。
2. 形 B を進めるなら、③ の峰のために **(a) 一艘目の船を手前へ動かす（形 A と同じ美術の誘導）か、(b) ③ を ② より低く・手前に置く目標を緩めるか**。
3. **① と ②、② と ③ の間を藍にして形で分けるか、原画のように白・水色で埋めるか**。形で分けると、原画の ② ③ の区域の上の方が藍になる（S11 の L6-label・P2-top が通らない）。
4. 形 A を進めるなら、**一艘目の船を手前へ動かす（倍率 0.7434）美術の誘導を認めるか**。

## 9. していないこと

- git の add・commit・push（この記録を書いた時点）。

## 10. 進行役の判断で決めたこと（Q24。理由と落とした案）

| 決めたこと | 理由 | 落とした案 |
| --- | --- | --- |
| 形の二つのやり方 A・B を別々に作って並べる | ③ を表す形に、別の小さな波（船が動く）と段（船は動かない）の二つの筋があり、どちらが利用者の読みに近いかは絵で決めるしかない | 一つに決めて作る |
| 白い粒は材質の点の関数を外して消す | 粒は材質の点だけから来ていた。白の印は一つにつながっている | 点を小さく・まばらにする（Q33 は本体に描かないこと） |
| 内の縁の白は面の上の規則で藍にする | 原画カメラからの投影を使わずに（G1）、縁の稜の白を見えない側へ移せる。座席などほかの視点でも同じ縁がそろう | 原画視点の画素で塗る（投影になる） |
| 形 B の材質にも見本04 の主役波で決めた内の縁の規則を当てる（`asm5_b_edge.py`） | そのまま回すと形 B だけ波頭の回り台 45° に白・水色の帯が残り、形だけを比べられない | 形 B の係の規則のまま |
| 直しの回は批評の順位で形 B から | 批評が形 B を強い土台とした | 両方を同じだけ直す |
| 形 B の ③ の峰（L1-3・L2-3）は直さずに尋ねる | 船の射線の禁止域で、船を動かすか目標を緩めるかの二択になる。どちらも新しい美術の判断 | 黙って船を動かす（二つ目の美術の誘導が増える） |
| 形 A の G1 の 4 三角形を残す | 0 にすると ② の峰が鞍より前に出ない（L2-2 0.25〜0.5 m） | ならしを強める |
| P1-mid・P1-cells は形で追わない | 原画では爪の群れで、Q33 は浪尖より形を先にと言っている | 白・水色の模様を面に描く |
| 波頭の爪 48 本は出さない | Q33-6 | 見本04 の爪を新しい頂に載せる |
