## 後続の再検査一覧

1. **物理検証は実施しない**：2026-09-25の制作指示で物理を二次目標とし、動きのもっともらしさを目視で確認するだけにする。21〜25の物理基準（理論誤差・粒子間隔/刻み・静水/収支/反射）は行わない。17/19の2球を波浪の物理基準へ読み替えない。
2. **主役波の時間密度**：実際の巻き込み/尖端・白波模型を作ってから、30/60/必要90Hzで同一運動を比較する。小試料の最大保持差にはdomain外縁の消失が含まれ、波頭知覚値ではない。
3. **形式の改修**：精度・圧縮・容量削減・streaming・chunkingを変えるたびに、全時刻の元形状・法線・接続・表裏・bounds・深度/影を再確認する。
4. **操船の照会データ**：GPU描画のVATだけでは流体の物理query/浮力を与えない。高さ一意でない巻き波を含む照会契約を別に設計する。
5. **描画と美術**：現shaderは比較用の不透明照明。最終NPR、白波、透過/重なり、深度、影、近接視点を同一条件で評価する。
6. **機器gate（新しい作業計画の番号34：HMD実機門）**：HMDと対象platformが決まったら、実両眼/SPI/頭部運動/再投影/CPU・GPU p95/p99/最大負荷・切替・総メモリ・読み込み/快適性を測る。PC人工2視点で代替合格にしない。

HMD待ちは独立した制作・美術作業を全停止する理由にはしない。実機条件を未完了として保持し、進行役の各番号レビューと完成点での利用者確認を通して順に進める。
