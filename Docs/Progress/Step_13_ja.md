# 13：白波の爪と前景の波形模型

日付：2026-09-24。結果：静止した白波の形と奥行きを確認した。発生・消滅・飛沫・流体に追従するアニメーションは未実装。

[空シーンからのBlender生成](../../Blender/M1_Composition/generate_foam.py) で9組の枝分かれする爪、波頭の帯、前景の小さな波形と白い縁を作った。30個の閉じたメッシュはすべて非多様体辺0、正の幾何体積を持つ。これらは水の物理量の検証ではない。制作元 `M1_Foam_Static.blend`、出力 `foam_static.fbx`。

Unityは頂点6,288個を実際に読み込み、非有限値がないこと、全材質の参照、奥行きがあることを確認。原画の白い爪と青い前景の三角形を観察して作った粗い構図模型で、原画の線・泡密度の再現は今後の課題。
