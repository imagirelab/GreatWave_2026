# 09：静止船とPC視点

日付：2026-09-24／結果：新規の検証用船と着座視点を作成し、視点・停止・リセットの処理を数値検査した。実寸感と快適性はHMDがないため保留。

船は新しく配置した箱形部品だけで作った静止した検証台。史実の船体復元ではなく、浮力・操船・波を備えない。全体寸法の実測は約幅2.51m・長さ7.49m・高さ1.23m。甲板上面Y=0.30m、座面Y=0.75m、船縁上面Y=1.05m、目の高さY=1.50m。目は甲板から1.20m、座面から0.75m、船縁より0.45m高い仮設定で、実機着座時に調整する。

| PC操作 | 動作 |
| --- | --- |
| 右マウスドラッグ・矢印 | 座席から見回す。位置は移動しない |
| R | 初期の着座視点へ戻る |
| Space | 視点の停止・再開 |
| Esc | 視点を停止 |
| Q | アプリを終了 |

日本語の案内と「PC確認版 / HMD未検証」を画面へ表示する。通常起動ではアプリ側からXR表示を開始しない。OpenXRネイティブプラグインの起動前探査は実行され、runtime未導入の警告を残す（[10](Step_10_ja.md)参照）。将来 `--vr` を明示するとXR起動を試し、表示サブシステムが起動できなければPCへ戻る。VR中はPC視点更新を停止し、TrackedPoseDriverに頭部姿勢を任せる。VR中のRはruntimeの再センタリング要求に使う。このVR経路の実機成功は未検証。

[実測JSON](../Evidence/M0/09_desktop_controls.json) には視点変化、停止中の不変、リセット、目と船縁の位置を保存。数値判定はすべて合格。ここでは物理キーボード・マウスを人が操作した試験とは区別している。PC実行版の入力経路と見た目は10で追加確認する。

再生成は `M0BoatBuilder.Create`。ローカル元ログは `Unity/Logs/09-boat.log`。コンパイルと生成は終了コード0、実機の両眼・頭部移動は保留。
