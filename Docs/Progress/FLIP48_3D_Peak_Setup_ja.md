## 2. 選んだ物と計算する物

| | 値 | 理由・出どころ |
| --- | --- | --- |
| 入ってくる波（選んだ） | Tanaka（1986）の厳密な孤立波、H0/h0 0.3（頂 5.10 m、速さ 14.687 m/s、F 1.13752）、まっすぐな頂、初めの頂 x 107 m | FLIP46 の解き手 g46_solitary をそのまま使った【計算】。0.3 は Pick & Feddersen 2026 の 1/10 の勾配の範囲（0.2〜0.3）の中【文献、FLIP47 targets_ja.md §3.1 から】 |
| 海底（選んだ） | z_b = −max(1.7, 17 − max(x − 143, 0)/10 · sech²(k y/17))。真ん中の断面は 1:10 で x 296 m から水深 1.7 m（0.1 h0）の棚 | GG06 の尾根の形（Guyenne & Grilli 2006）と FLIP47 の 2D の S2（1:10 で 0.1 h0 の棚、前の面 84〜91°【測定】）を合わせた。尾根が細いほど巻きが細く強い（Grilli ほか 2010、k 0.1 と 0.25 の比べ）【文献】 |
| k | R0 は 0（横に一様な板）、R1 は 0.35 | k の決まり（下）。k 0.35 の斜面は最も急な所で 19.3°、k 0.5 は 26.3°【計算】 |
| 水槽 | x 0〜360 m、横 0〜85 m（y = 0 は対称の面、y = 85 m は壁）、縦 −19〜+17 m、粒子 0.5 m、FLIP の受け渡し | APIC は y = 0 の壁に偽の横流れを作る（FLIP46 §3）【測定】 |
| 計算する物 | 真ん中の伸び、崩れ方、巻きの形と幅、横への剥がれ、唇 | 重力だけ。途中で形へ寄せる力はない |

正直に書く所：振幅と尾根を選んだので、「盛り上がりが尾根の軸に出ること」と「横の頂が約 5.1〜5.5 m であること」は選んだ物で決まる。計算の結果として言えるのは、真ん中がどこまで伸びてどう巻くかと、巻きがどれだけ横へ広がるか。1:10 の軸と 19〜26° の斜面は急で、自然の岩礁や棚の縁の範囲の中と読むが確かめていない【推測】。

k の決まり（R1 の前に決めた）：P05_k0p5_W136 の真ん中の巻き始めが x ≤ 300 m で前の面の弦 ≥ 55° なら k 0.5、でなければ 0.35。g46_analyze の読みは x 300.5 m・弦 21°（最も巻いた時 52°）なので **k 0.35**【測定】。

## 6. 分かっている危うい所

1. 真ん中が 3D で巻かないかもしれない：細い尾根では水が横へ逃げる（FLIP46 k 0.5・1.0）【測定】。棚が水深で崩れを決めるが、巻かずに砕け波（ボア）になることもある。R0 が 2D の部分を分け、R2 (a) で尾根を広げる。
2. 巻きの幅：斜面が真ん中のすぐ後に崩れる水深になる（k 0.35 で水深 ≤ 3.4 m の半幅が x 280・296・310 m で 4・17・22 m）。巻き始めで 1.5〜2.5 Hc、着水で 3〜4 Hc になりうる【推測】。
3. 真ん中 ÷ 横が 1.5 に届かないかもしれない：線形の見込みは FLIP に比べ大きく出る（P05 で 1.90 対 1.07）【測定と計算】。|y| = 4 Hc（約 32 m）は斜面の上（水深 6.5 m）なので、P4b が外れやすい。
4. 棚の水深 ÷ 波の高さは 0.33 で、2D の S2（0.17）より S5 に近い。前の面が 84° より寝るかもしれない。R0 が 3D の前に測る。
5. 粗さ：棚は粒子 3 層、唇 2〜3 m は 4〜6 粒子。数は収束した値ではない（FLIP47：粒子 0.5 → 0.25 m で空気の穴 +37 %）【測定】。
6. 初めの状態：孤立波は平らな海底の解で、初めに 14 % が尾根の上にある。2 コマ目で 2〜6 % の差が出る見込み（FLIP46 と同じ種類。GG06 は頂が尾根の始まりの 9.5 m 先）。
7. 下流の壁 x 360 m：横の頂が 17.4〜17.7 s に着き、水が棚に溜まる。横の端は x ≤ 340 m・t ≤ 17 s で読む。
8. 平均の水面から読む水の量には、粒子から作る水面のずれ（静かな所で 0.03〜0.05 m 上がる、FLIP46 §3）も入る。FLIP46 の 3 本で 0.36〜1.07 % に出た（k 1.0 の 1 本は 1 % を越えた）【測定】。H の水の量が外れた時は、粒子の数ではなくこのずれを疑う。
