# 美術の要求書（主役の大波）

この文書は、利用者が求める美術の要求を一か所にまとめたものである。利用者の言葉（制作指示 Q8〜Q31）から進行役がまとめ、利用者が「基本对，我来补充」（Q30）と答えた一覧に、Q30-2 の補足を加えた。**美術が要求に届いたかは利用者が判定する**（Q29・Q30）。進行役は、見本を出す前に、測れる規則（下の「測る規則」）を必ず自動で確かめ、通らない見本は出さない。新しい利用者の言葉があれば、この文書へ足す。

原文は [制作手順](../Workflow/Production_Workflow_ja.md) の各 Q にある。

## 6. 進め方

- 美術の作業は「美術の見本」として小さく区切って利用者に見せる。利用者の確認を閉じる条件にする（Q29・Q30）。
- 見本を出す前に、上の「測る規則」を自動で確かめる。通らないものは出さない。
- 進行役とサブエージェントの目で見た審査は、見本を良くするための道具にとどめ、閉じる条件にしない（Q30-2）。
