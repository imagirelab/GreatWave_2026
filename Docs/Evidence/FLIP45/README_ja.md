# FLIP45 V1（3D の向きの集まりの粗い下見）と、形の比べの図

- 何か：3D の流体計算 FLIP45 の下見 V1 と、その形を原画・論文と比べた図を、ローカルの記録（`Unity/Build/FLIP45/`、Git 対象外）からバイトのまま写した 4 ファイル（このフォルダーの 3 つと [../FLIP45Diag/](../FLIP45Diag/) の 1 つ）。写した日 2026-10-13。中身は変えていない。SHA-256 は下の表。
- 計算：Fochesato, Grilli & Dias 2007 の向きの集まり（水深 20 m の平らな底で、向きの違う波を一点に集めて崩す）を、Houdini FLIP の 3D の水槽で解いた。粒子 0.5 m・格子 1 m、重力だけ・水だけ。y = 0 を対称の面にして半分の幅を解いた。粗い下見なので、再現の判定には使わない（走らせる前に決めた計画のとおり）。
- コマと時刻：t = (コマ − 49) ÷ 24 s（例：コマ 1330 = 53.375 s）。x は造波板からの距離、y は対称の面からの横の距離。
- 主な数【測った】（V1 の解析 ana.json と形の比べから）：
  - 巻き始め（y = 0 の断面に初めて鉛直の接線）：コマ 1330、t 53.38 s、x 242.5 m（論文 48.2 s・211.7 m より 11 %・15 % 遅く先）。
  - 頂の高さ η_c 6.19 m（論文の BEM 7.16 m の −13 %）、頂から後ろの谷 H1 9.45 m（論文 10.76 m の −12 %）、頂の横の長さ ℓ 66.5 m（論文 66.0 m、決めた幅 62.7〜69.3 m の中）。
  - 唇は小さい：いちばん巻いたコマ 1347（t 54.08 s）で唇の届く距離 1.70 m・厚み 0.90 m。着水はコマ 1360（t 54.63 s）。
  - 前の面の弦（0.1〜0.5 η_c）：V1 19.6°、論文の BEM 25.8°（論文の 9 例で 11.8〜25.5°）、原画 64.3°。
- 読み：V1 と原画の差の大きな部分は、計算の細かさではなく波の崩れ方の型による、と読む【考え】。根拠は、論文の BEM の波そのものの前の面が 26° 前後で、V1（約 20°）は論文の側にあること【測った】。向きの集まりは平らな底で波の険しさで崩れる型で、原画の切り立った壁と空洞は、急な海底で水深に限られて崩れる型の側にある（Pick & Feddersen 2026）【文献】。
