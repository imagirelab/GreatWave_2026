# FLIP47（2D の板で海底と波を変えた実験）の証拠の写し

- 何か：2D の流体計算 FLIP47 の図・動画・数の表を、ローカルの記録（`Unity/Build/FLIP47/`、Git 対象外）からバイトのまま写した 13 ファイル。写した日 2026-10-13。中身は変えていない。SHA-256 は下の表。
- 計算の共通：Houdini FLIP の 2D の板（板の厚さ 格子 4 個 = 2 m、両面は滑る壁）、粒子 0.25 m・格子 0.5 m、重力だけ・水だけ。主の読みは板の層 z −0.25 m の断面。x は Feddersen ら 2024 の座標（m）、h0 = 19 m。
- 原画の物差し（STUDY52 の measure_mask、頂の高さ η_c で割った値。括弧は原画の 4 つの読みの帯）：前の面の弦（0.1〜0.5 η_c）64.3°（60.5〜78.0）、前の足 0.254（0.18〜0.28）、覆いの面積 0.186（0.143〜0.229）、唇の下の空気 0.541（0.49 以上）、唇の厚み 0.350（0.32〜0.39）、後ろの角（0.7〜0.9 η_c）31.3°（29〜38）、0.7 η_c の幅 1.32（1.02〜1.42）。score3 は弦・足・覆いの 3 つの帯の外れの和（0〜3、0 が 3 つとも帯の中。走らせる前に決めて凍結）。
- 速度の受け渡し：B の海底の組（S1〜S6）と C の E1a は APIC（元の設定）。D で、APIC が板の層ごとに噴流の形をずらすと分かり、FLIP に直した。A の周期の波（P1c・P2c）は FLIP。
- 独立の確かめ：別の解き手 Basilisk（空気と水の 2 相）で同じ海底の孤立波を解くと、巻く途中の score3 の最小は S2 0.22・S5 0.61・S1 1.42 で、S2 < S5 < S1 の順は FLIP と同じ。着水のコマで比べると順は逆になる（[Basilisk_Check_ja.md](../../Research/Basilisk_Check_ja.md)、動画と表は [../Basilisk/](../Basilisk/)）。

## 読む時の注意（別の確かめ役の指摘、ローカルの記録 `Unity/Build/FLIP47/record_ja.md` の「周期の波の実験の確かめ」）

1. k8 の score3 0.00 は 1 コマだけの最小で、前後 0.25 s のコマでは 0.35 と 1.78【測った】。その時刻は、体積の直しが働いている後半（P1c では 47 % のコマで直しが上限 −0.002 /s に当たった）。体積の直しの影響の小さい候補は k2 のコマ 1414（score3 0.23）。
2. 頂のとがり：k5（12.45 m）と k8（12.43 m）の巻き始めの頂は、1〜2 格子の幅の細い水の柱を含む。水面を 2.5 m の中央値でならすと 10.45 m・10.23 m【測った】。とがりは 100 s より後の回に出て、k2〜k4 にはない。解析にこのとがりを除く手はまだない。
3. 体積の直しが入口の帯の水を抜く：帯の上流の端（x 160〜240 m）の平均の水面が P1c で −2.7 m（182 s）まで下がり、直しの積分が大きい計算ほど下がりが大きい【測った】。帯は流速を寄せるだけなので、帯の中で除いた水を外から戻せないと読む【推定】。後半に崩れる所が沖へ移ったのはこのためと読む【推定】。
4. 数え落とした崩れ：P1c の 7 番目の来た波は 128.5〜131.6 s に x 623〜676 m で大きく巻いたが、崩れの選び方の決まりで落ち、k7 には浅い所（x 707 m、水深 5.3 m）の小さな巻きが入った。k5〜10 の繰り返しの数（崩れる x の標準偏差 36.7 m など）はこの取り違えを含む【測った】。
5. 細かさ：どれも粒子 0.25 m。粒子 0.125 m の確かめは、海底と波を決めるまで行わない（計画した判断）。唇の厚みは格子 2〜5 個ぶん。
6. 2D の板の計算で、横に同じ形が続く。3D は FLIP45 の向きの集まり（[../FLIP45/README_ja.md](../FLIP45/README_ja.md)）だけ。
