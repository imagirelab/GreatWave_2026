## 結果

### 1. R3 の記録を自分で読む（`k_r3.py`）

- 3319〜3889 コマで二つの記録にあるコマ（sec と hf を合わせて 652）は、全部バイト単位で同じ【測った】（C1 (a) と食い違わない）。
- 自分で取った線（sec の 0 の等高線、静かな水面から 25 m 下より上、その外は hf の z = 0 の節）で：巻き始め（頂から前へ 0.5 m の弦が 90° 以上）3714 コマ・154.708 s・x 508.35 m、頂 507.04 m・9.557 m。最初の接触（頂 ±30 m に 0.25 m² 以上の空気）3745 コマ・156.0 s・1.941 m²。頂の最大 9.567 m（3716 コマ）【測った】。`shape.json` の 508.31 m・9.557 m・1.94 m² と合う。
- 唇（頂から前へたどった x の極大の先と、その下の面の最も後ろの x の差）は 3744 コマで届く距離 3.85 m・厚み 1.03 m【測った】。FLIP42 の報告の 3.65 m・1.06 m とは読み方の細部が違う（下の面の終わりの決め方）ので、以下の比べはどれもこの自分の読み方を両方に当てた。
- かぶさった水が船体（±6 m）に入る最初のコマは 556 m で 3772、574 m で 3797【測った】。船からのクリップの終わり 3771・3796 コマ（157.083 s・158.125 s）と合う。
