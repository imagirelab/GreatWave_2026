# 教員からの設計依頼

以下は制作設計のために渡された日本語プロンプトです。このファイルは要求の記録であり、Rider の AI チャットでの設計が完了したことを示しません。

> 神奈川沖浪裏を3D CGのリアルタイム映像としたいです。浮世絵的なレンダリングの中を船に乗って北斎の世界を体験したいと思っています。HMDで船の上から波が見れたり、船が操作できると良いです。波は物理学、美学的な正確性を優先したいです。白波は、別計算で良いのでモデルとしてアニメーションさせたいと思っています。最終的に動かす環境はUnityを考えています。波はHoudiniで流体シミュレ―ションしたものをサーフェス化してリアルタイムに表現したいです。船などの静的なモデルはBlenderで作成したいです。このような作品を制作するための設計をお願いしたいです。なるべく細かくステップを分けて、少しずつ確かめながら作品を制作できるようしてください。
