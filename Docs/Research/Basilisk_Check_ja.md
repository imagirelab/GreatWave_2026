## 1. 方針

- 指令の順に、A（解き手の確かめ）→ B（本作の海底）→ C（広げた探し）で進めた。計算機と時間の都合で、A は 9〜12 段、B は 10〜11 段（S2・S5 は 12 段も。§5）、C は 10 段で走らせ、上位 3 つを 11 段で解き直した。
- 作者の設定：Basilisk の sandbox に作者が公開した風なしの算例 `sandbox/ffeddersen/shoal_RE0_BO4000.c`（SHA-256 `e09a4e6b…0ebd`）を見つけたので、指令のとおりそれを元にした（`Tools/Basilisk/gw_shoal.c`）。違いは §1.1。
- 論文の本文：出版社（cambridge.org）と著者のページ（falk.ucsd.edu）への接続は、この計算機の通信の決まりで止められていて、本文を読めなかった。論文の値は、指令と本作の記録（調べの文書）に写された値を使った【文献】。量の定義（§3.1）は、指令の言葉と本作の記録から組み立てたもので【推測】である。
- 原画の物差し：`Tools/GWWaveGen/ruler/s52_shape.measure_mask` をそのまま使った（変えていない）。原画の値（`shape_measures.json` の `print.cn`）をこの計算機で読み直し、7 つの量が同じ値になることを確かめた【測定】。

## 2. 目標

- A：論文の風なしの算例の値【文献】に、格子を細かくして近づくこと。Hb/h0 0.64、xbp/h0 42.05（論文の風の算例の幅 40.9〜42.2）、着水 t̃ 19.96、A_J/Hb² 0.219、A_O/Hb² 0.352、W/L 0.300、θ_O 29°、噴流の幅 約 0.05 h0。
- B：S1・S2・S5 を重力だけに近い条件（表面張力なし、粘りなし）で解き、原画の物差しで FLIP と比べる。FLIP の値【文献：指令】：S2 は前の面 84°・前の足 0.33・覆いの面積 0.140・着水の A_O/Hb² 0.32・Hb/h0 0.499、S5 は 59°・0.50・0.165・0.26、E1a（S1 にあたる）は Hb/h0 0.643・xbp 42.05・A_O は論文の 68 %・A_J は −9 %。
- C：勾配 1:5〜1:12、棚の水深 0.05〜0.3、a0 0.4〜0.7、段の形（急な段、二段）で 20 本まで。score3 で並べ、上位 3 つを細かい格子で確かめる。

score3【計算】：前の面の弦の角度（0.1〜0.5 η_c、原画 64.3°、帯 60.5〜78.0）、前の足（0.1 η_c の所の頂からの距離 ÷ η_c、0.254、帯 0.18〜0.28）、覆いの面積（÷ η_c²、0.186、帯 0.143〜0.229）の 3 つについて、帯の外の距離 ÷ 原画の値（1 を上限）の和。0 は 3 つとも帯の中。物差しで測るのは、覆いかぶさりが出たコマ（巻き始め）から最初の着水のコマまでの全部のコマ（Δt̃ 0.02）で、score3 の最小のコマと着水のコマを示す。

## 3. 結果

### 3.1 A：論文の風なしの算例の再現

量の定義（`Tools/Basilisk/post/gwpaper.py`）【推測：論文の本文を読めなかったので、指令と本作の記録の言葉から組み立てた】：

- 覆いかぶさった列：同じ x の縦の列に水の続きが 2 つ以上ある列（水面が x について多価）。
- 着水：唇の先の真下の隙間が 0.015 h0 以下になるか、空洞が閉じた空気の泡になった最初のコマ。
- A_O：覆いかぶさった列で、いちばん上の水の続きとその下の水の間の空気の面積（唇の下の空洞）。A_J：覆いかぶさった列の、いちばん上の水の続きの面積（唇が触れた後に触れた所より先に垂れ下がる唇も入れる）。
- θ_O：空洞の画素の主軸の角度。W/L：空洞の縁を −θ_O 回してから、軸のそろった楕円を当てはめた短い径 ÷ 長い径（Longuet-Higgins 1982 に倣った指令の読み）。
- 噴流の幅：着水のコマで、空洞の後ろの壁と唇の先の中ほどの x で、噴流の中の空気までの距離の最大 × 2。
- H：着水の時の頂の高さ（静かな水面から）。崩れる位置：着水の時の唇の先の x。この読みで論文の Hb・xbp に合った（下の表）。論文の Hb・xbp がこの定義かどうかは【推測】。

## 4. 分かったこと

1. **Basilisk で論文の風なしの算例を再現できた**。格子を細かくするほど論文の値へ近づき、12 段（論文の 4 倍粗い）で着水の時刻・高さ・唇の先の位置は 0.3 % 以内、A_J は −2 %、A_O は 91 %、θ_O は 1.4° 差【測定・計算】。合わないのは W/L と噴流の幅で、定義の違いの見込みが高い【推測】。解き手として、この計算機での Basilisk は正しく動いている、と読む。
2. **「急な海底と浅い棚で、巻きが原画に近づく」は、別の解き手でも出た**。重力だけに近い条件で、論文の海底 S1 は score3 1.42（前の面 33°、前の足 0.81）、S2 は 0.21（91°、0.23）、S5 は 0.66（69°、0.44）【測定】。順番は FLIP と同じで、S2 の着水の時の頂の高さ（0.486 と 0.499）と覆いの面積（0.147 と 0.140）は FLIP とよく合った。FLIP の A（E1a）で空洞が論文の 68 % だったのに対し、Basilisk は 91 % まで近づいた。FLIP の小さい空洞の一部は FLIP そのもの（空気なし、粒子の細かさ）による見込みがある【推測】。
3. **最も原画に近い条件は、勾配 1:8〜1:12 で水深 0.1〜0.2 h0 の棚へ上がる海底**（C04、S2、C08）。前の面の角度・前の足・覆いの面積の 3 つを同時に原画の帯へ入れたコマがある（C04 の 10 段で score3 0.16）【測定】。
4. **重力だけの孤立波では、背が立たない**。背の角 7〜14°（原画 31°）、0.7 η_c の幅 2.2〜3.3（原画 1.32）。海底を変えても動かない【測定】。背は初めの波の形（孤立波の長い背）から来ていて、海底の外の手が要る見込み【推測】。
5. **score3 は格子の段と初めの置き方で 0.1〜0.6 動く**。10 段だけの順位はおおよその目安で、11〜12 段と、頂を足から 15 h0 に置いた確かめが要る【測定・推測】。
6. 表面張力（Bo 4000）と粘り（Re 4×10⁴）は、この大きさの巻きの形には数 % しか効かない（S1 と S1p、Re 1×10⁶ と粘りなし、作者の公開ファイルの σ = 0 の解き直し）【測定】。実物の大きさ（h0 19 m、Bo 約 5×10⁷）の重力だけの計算と、論文の実験室の大きさの計算の差は小さいと読む【推測】。
