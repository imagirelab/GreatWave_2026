# GreatWave_2026

『神奈川沖浪裏』の没入型3D/VR表現に向けた動的波浪と浮世絵表現の研究制作。

## Unity プロジェクト

- 使用エディター: Unity 6000.4.3f1
- Unity Hub でこのリポジトリのルートを開く。
- 現在の主要シーン: `Assets/Scenes/Showcase_01.unity`
- ビルド対象のシーンはまだ `ProjectSettings/EditorBuildSettings.asset` に登録されていない。

`Assets/`、`Packages/`、`ProjectSettings/` と Unity の `.meta` ファイルを管理する。`Packages/com.coplaydev.unity-mcp/` のローカルソースも含める。パッケージ参照の整合性は今後確認する。

Unity が再生成する `Library/` などのキャッシュ、実行結果の `outputs/`、個人の作業記録、スクリーンショット群、復旧シーンはリポジトリに含めない。元のファイルはローカルに残している。

この初期登録は既存の Unity 試作を保存するものであり、波浪の物理的妥当性や HMD 上での動作を検証した完成版を意味しない。
