# GreatWave_2026

『神奈川沖浪裏』を題材とした3D作品の制作準備用リポジトリです。現在の作業ツリーには、制作物や試作を置いていません。

| フォルダー | 用途 |
| --- | --- |
| `Houdini/` | 波浪の流体シミュレーションとサーフェス化 |
| `Blender/` | 船などの静的モデルの制作 |
| `Whitewater/` | 白波の別計算とアニメーション |
| `Unity/` | リアルタイム表示、HMD体験、船の操作の統合 |
| `Docs/` | 設計と各段階の確認記録 |

制作の条件と手順を確認してから、各フォルダーに成果物を追加します。
