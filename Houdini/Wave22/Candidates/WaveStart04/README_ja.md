## 応答の事前定義

主観測は**未補正のsolver surface符号場の水位**と**PFS表示面の絶対水位**であり、約10mmの定義差を差し引いて水深を補正しない。
Volumeの `isSDF=false` という観測を無視して「認証済みSDF型」と呼ばない。
旧局所ゲージ/mesh最初のray hitだけでは底連通や全領域非砕波の証明にならない。

各観測方式・各測点で、新runの二静水窓を使う。μは後窓平均、σは二窓の平均回りRMSの大きい方、Eは**両窓全標本**のmax|η−μ|、q=max(1mm,3σ,E)とする。
既存OFF値を閾値へ差し替えず、式と窓だけを事前に固定する。
60Hz rawでη−μが同符号かつq以上の5連続標本（4/60秒にわたる）を最初の応答超過として記録する。
PFSは別の30Hz観測として3連続標本を用いる。η(t)−η(t6)による同じqの超過時刻は補助欄だけに保存し、水深・体積補正や主判定の代用にしない。

極値候補検出のみ5点対称平均を使用し、[6,9.25]外のpaddingや片側平均はしない。
山は前値より厳密に大きく、後値以上（谷は逆）とし、同値plateauは最初の点のみ候補とする。
rawのμからの振幅がq以上、かつ平滑値の左右それぞれ±.375秒内のprominenceの小さい方がq以上を要求する。
左右窓が平滑可能範囲からはみ出す候補は切断候補として保存し、合格鎖へ入れない。
同符号の三測点鎖の全組合せについて、隣接遅れが厳密に `2/60 < Δt < .75秒` のものを全件列挙する。
正負両方を合わせて一つだけなら「有序特徴鎖を一つ観測」、複数なら多義、超過があって鎖なしなら順序未確認、超過なしならこの窓/閾値では未検出とする。
理論遅れに一番近い鎖を選ばず、未検出から波動の不存在を断言しない。周期・波速・無反射の合否は全て別途保留する。
