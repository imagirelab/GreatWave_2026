# 参照形の解放と、有限時間の制御後の自由発展

**設計案。ここに書く比較計算はまだ実行していない。** 次の課題を「低い隆起 → 高い峰と巻いた開口 → 制御を切った水舌の落下・接触」に分ける。静的な参照OBJから分かるのは形であり、形成の速度場や自然な砕波時刻ではない。

## 1. 既存資料から確認できること

[旧HIP調査](../wave_tank/旧HIP調査.md)では、POP VOPが固定した第69フレームの形状由来の体積勾配を負にし、100倍して `force` へ書く経路を確認した。新しい `OUT_dynamic_model_vdb` は当該POP VOPの参照先ではなかった。これは接続とコードの読取り結果であり、旧 `1.abc` の生成履歴や、その力で良い砕波が得られたことの証明ではない。

また、[映像の観察記録](../../Blender/great_wave/docs/milestones/2026-09-24_motion_targets.md)の展示映像では接触から消散まで同じ波を追えていない。以下の判定は、その見えない過程を新しい計算で提示するためのもの。

## 2. 二つの方式が答えられる問い

| 方式 | 入力と時間発展 | 確認できること | 確認できないこと |
| --- | --- | --- | --- |
| **A：参照形を初期水体として一度だけ配置** | 閉じた水体を粒子化し、記録した初速からFLIPで解放する。以後は目標形への追従を行わない。 | その初期姿勢から水舌が下がり、周辺水面と接触するか。再構成によって巻いた開口が失われないか。 | 低い海面から参照形へ形成されたこと。初速をOBJから実測したという主張。 |
| **B：低い水体を有限時間だけ制御し、その後解放** | 初期水体は低い隆起。内部へ広がる目標速度に有限の強さで近づけ、制御を滑らかに0へ戻す。圧力計算は継続する。 | 外部から与えた制御で高峰・前伸しを作れるか。制御を切った後にも巻下げと接触が続くか。 | 無外力の自然海浪として形成したこと。制御中の形だけを見て、流体の自由発展を実証したという主張。 |

**次の順序はAで解放部分を確かめ、その後Bへ進む。** Aの成功をBの形成過程の代用にはしない。

## 3. 共通の初期水体

- 参照の主水体と周辺水面を閉じた体積として準備する。以前のBlender場面で「白波」と名付けた面集合には主波の厚い唇も含まれるため、名称だけで全体を除かない。細い爪などを簡略化するときは元OBJと変更箇所を保存する。開口を埋める修復は採用しない。
- 体積の和集合を作ってから一度だけ内部へ粒子を配置し、重複する二つの粒子源を重ねない。SDFの内外と、中央・両肩の断面を確認する。閉じた体積を必要とすることはSideFXの[流体ソーシング仕様](https://www.sidefx.com/docs/houdini/fluid/sopsourcing.html)にも記載されている。
- Bの初期形は折返しのない高さ場とする。巻いた模型を縦に縮めただけの形を「形成前」と呼ばない。Aと比べる際は同じ槽・水位・総水量を目指し、隆起を低くした分を幅や周辺水位へ配分した量を記録する。
- 最初の比較は全水深の粒子を使い、再生成・追加放出・Sinkを使わない。粒子IDと属性質量の総和、体積場の体積、表面再構成の体積は別々に記録する。粒子数一定だけで質量・体積保存を合格にしない。

## 4. Bの最初の実装案：体積内の流れを制御する

### 勾配吸引を主制御にしない

全粒子を目標表面の最近点へ投影したり、`−φ∇φ` でゼロ面へ繰り返し集めたりしない。内部を満たす流体を表面の殻へ変える制御は不採用とする。符号付き距離φの `−∇φ` は、そもそも表面への復元力とは異なる。旧HIPの負勾配が実際に殻を作ったとは未確認であり、その現象を既成事実としては扱わない。

目標は、後背の持上げ、峰付近の前進、唇の回転を水体の有限の領域へ与えること。参照形は高峰・唇・内側開口の位置と厚さを比べるために使う。全表面への吸着は要求しない。

### 制御速度と更新式

最初は独立した二つの滑らかな循環場だけを作る。広い持上げ用と、上部の前伸し・回転用である。HoudiniのYを鉛直、Xを前方とし、例えば滑らかな関数ψから `u_g=(∂ψ/∂y, −∂ψ/∂x, 0)` を作る。空間窓と幅方向の強弱はψの中に含める。これは提案する解析的な速度設計で、任意のC形を実現できるという保証ではない。床と制御領域の外側で窓とその一階微分を0へ戻す。後から速度へ空間マスクを掛ければ、元の発散0の性質は一般には失われる。

別の構築候補には[POP Curve Incompressible Flow](https://www.sidefx.com/docs/houdini/nodes/dop/popcurveincompressibleflow.html)がある。公式仕様では曲線から発散のない速度場を作り、通常は `v`、`Treat as Wind` では `targetv` と抵抗属性を変更する。遠方の効果は自動的に厳密な0にならず、3Dの水体へ2D Flowをそのまま使わない。今回は上記の二つの解析場を先に試し、両方式を一度に混ぜない。

FLIP Solverの **Particle Velocity入力** に、次の更新だけを行うPOP Wrangleを置く。位置Pは書き換えない。公式資料で、この入力は粒子速度から格子への転送より前にあり、POPによる `v`・`targetv`・`force` の変更を受け付けることを確認した。[FLIP Solver](https://www.sidefx.com/docs/houdini/nodes/dop/flipsolver.html)

```text
α = 1 − exp(−w(t) m(x) Δt / τ)
Δv制御 = α (u_g − v直前)
v直後 = v直前 + Δv制御
```

τは応答時間、mは有限領域の滑らかな強度、wは時間窓で、mとwは0～1とする。いずれも条件ファイルへ保存する。初回はτを少なくとも最大サブステップ幅の4倍とし、毎ステップの完全な速度置換に近づけない。この値は試験上の制限で、物理定数ではない。合成した粒子速度が発散0とは限らないため、その後のFLIP圧力投影を通す。圧力投影後に目標速度を再び上書きしない。時間窓は実際のサブステップ時間で評価する。[POP Wrangleの時間属性](https://www.sidefx.com/docs/houdini/nodes/dop/popwrangle.html)

### その他の公式機能との違い

| 機能 | 今回の扱い |
| --- | --- |
| [Gas Target Force](https://www.sidefx.com/docs/houdini/nodes/dop/gastargetforce.html) | Liquid Modeは流体と目標をSDFとして扱い、Animated Goalと距離による力の調整がある。ただし、このノードの存在だけで目標体積・厚さ・停止後の挙動が保証されるわけではない。上記の速度制御で不足する理由が分かってから、別の比較条件にする。 |
| [Gas Guiding Volume](https://www.sidefx.com/docs/houdini/nodes/dop/gasguidingvolume.html) | 誘導面・速度を圧力と粘性用の衝突場へ組み合わせる機能。Sinkには粒子削除があり、通常の形状吸引とは違う。質量と解放を切り分ける初回には採用しない。 |
| [Guided ocean waves](https://www.sidefx.com/docs/houdini/fluid/sopoceanwaves.html) | Boundary Flowから速度・圧力を与える経路。槽の外側から造波する次の候補であり、中央の水体を参考形へ合わせる今回のBとは別条件。 |

## 5. 次の最小比較：最大三条件

以下の時間は最初の比較窓の提案で、展示から得た自然な砕波時間ではない。形の倍率を変える場合は、Hと重力時間 `sqrt(H/g)` を併記する。

| 条件 | 0～約3秒の内容 | 必須の比較 |
| --- | --- | --- |
| **A0** | 参照形から開始。初速0、目標への制御なし。既に実施済みなら同条件を再計算しない。 | 初期・下降・初接触・接触後の固定側面と実断面。接触まで見えなければ解放時間だけを延ばす。 |
| **B0** | 折返しのない低い隆起、初速0、制御なし。 | B1と同じ初期粒子・乱数・槽・時間刻みを使用する対照。 |
| **B1** | B0と同じ初期状態。0～0.25秒で制御を立上げ、0.25～1.25秒で持上げから前伸しへ配分を移す。1.25～1.75秒でwを0へ落とし、以後約3秒までは制御なし。 | 高峰と開口が現れる時刻、制御停止、自由な下降と接触を一続きで表示。参照姿勢を静止保持する区間は入れない。 |

各条件は最初に6フレームだけ確認し、健全なら24 fps・72フレームへ進める。第1フレームをt=0とすると末尾の計算時刻は71/24秒である。解像度・振幅・τの多数探索は同時に行わない。B1の制御終了時に良い形がない場合は、白波を加えず「形成未達」と記録する。終了時の状態を保存し、w=0の制御ノードを残した続行と、そのノードを外した短い続行が一致するかを確認すれば、隠れた制御の残存を検出できる。

## 6. 保存する証拠と、具体的な失敗理由

- **制御仕事：** 各サブステップで制御直前・直後の速度差を保存し、`ΔW = Σ ½ m_i (|v直後|²−|v直前|²)` と `ΔJ = Σ m_i Δv制御` を累積する。正・負の仕事も分ける。これはその速度更新による粒子求積の推定で、圧力投影・重力・境界・数値散逸を含む全エネルギー収支ではない。m_iの意味と単位を確認してからJ・N·sを付ける。force属性方式へ変更するなら、力と加速度の区別を確認し、`ΣF制御·v中間Δt` を記録する。[POP Forceの質量の扱い](https://www.sidefx.com/docs/houdini/nodes/dop/popforce.html)
- **停止後：** w、制御を受けた点数、最大 `|Δv制御|`、累積仕事を保存する。1.75秒以降に制御仕事が増えるなら自由発展とは呼ばない。
- **水量と厚さ：** ID・属性質量総和、体積場と表面の体積、中央・両肩の内部粒子分布を保存する。表面だけが似て内部が空になる場合は不採用。細い唇を数セル未満でしか表現できない場合、解像度不足と形の失敗を分ける。
- **造形：** 同じ高峰と唇の前後距離、開口の輪郭、背と唇の高さ、最初の接触時刻を追う。[動きの判定表](../../Blender/great_wave/docs/milestones/2026-09-24_motion_targets.md)を使い、静的OBJから接触時刻を作らない。

| 起こり得る失敗 | 最初に確かめる原因と切分け |
| --- | --- |
| Aで開始直後に開口が消える | 元の閉鎖処理・SDF・粒子化・表面再構成で空間を埋めていないか。計算前の断面で分かる問題を力で補わない。 |
| Aが全体として落ちるだけ | 初期運動量と周辺水面の支持が、進行する巻波に相当していない可能性。初速0の解放試験の限界として扱う。 |
| Bで形が育たず力だけ大きい | 収縮的な制御が圧力投影で打ち消される、持上げる水量や循環経路が不足する、目標へ運ぶ時間が短い可能性。投影前後の速度を比較し、まず原因を選ぶ。 |
| Bが高い薄膜や表面殻になる | 上面だけの吸引、強すぎる局所制御、厚さ未解像の可能性。内部断面を見て、吸引強度の追加で埋め合わせない。 |
| Bで横長の梁になる | 制御場が幅方向に一様。左右で異なる有限の強度と中央・肩の高さを確認する。 |
| 制御を切ると直ちに潰れる | 制御中の形が持続的な外力に依存していた可能性。速度と圧力の停止前後を確認し、停止時刻を隠して成功にしない。 |
| 高速噴出、体積変化、壁で再上昇する | 急な制御切替、局所速度差、圧力・格子・境界の影響を確認する。壁際の最高点を目標の主峰と取り違えない。 |

合格の範囲は、Aでは**参照形からの解放・接触**、Bでは**記録された美術制御による形成と、その停止後の流体発展**に限る。どちらも、そのまま無外力の実海浪、物理的収束、HMD体験の完成を意味しない。
